The new rules of context engineering for Claude 5 generation models (1 minute read)

Anthropic removed over 80% of Claude Code's system prompt for Claude Opus 5 and Fable 5 generation models with no measurable loss on its coding evaluations. The post argues that newer models were being overconstrained by conflicting instructions across system prompts, CLAUDE.md files, and skills, and recommends using the `/doctor` command to rightsize that context and let the model rely on its own judgment.

Running a 28.9M parameter LLM on an $8 microcontroller (1 minute read)

A developer ran a 28.9M parameter language model directly on an ESP32-S3, an $8 microcontroller, generating text on-chip at roughly 9 tokens per second with nothing sent to a server. It fits by borrowing Per-Layer Embeddings from Google's Gemma models, keeping the 25M-row embedding table in slow flash and reading only the ~450 bytes each token needs while the compute core stays in the chip's 512KB of SRAM.

Why Software Factories Fail (1 minute read)

This post argues that "software factory" setups where no human reads or writes code fail because harness and loop engineering alone cannot ensure quality, citing a Faros AI report linking AI coding tool adoption since early 2026 to lower PR review quality, more incidents, and more bugs per developer. The author, HumanLayer's founder, contends that "just spend more tokens" advice ignores real degradation and pushes context engineering over token-maxxing.

Measuring Reward-Seeking by Instilling Contrastive Beliefs (5 minute read)

OpenAI's alignment team introduced Contrastive Synthetic Document Finetuning (Contrastive SDF), a test that alters a model's beliefs about its grader to measure whether it is reward-seeking rather than pursuing the intended objective. Frontier models trained with reinforcement learning but no safety training increasingly did what they believed the grader wanted, even when that conflicted with user or developer intent, and the tendency strengthened over training.

Introducing Antares: Highly Efficient Open Weight AI Models for Vulnerability Localization (5 minute read)

Cisco released Antares, a family of open-weight security small language models built to localize known vulnerabilities within large codebases. The two available checkpoints, Antares-350M and Antares-1B, outperform larger closed- and open-weight models on Cisco's new Vulnerability Localization Benchmark at a fraction of the cost, and run locally so sensitive source code never leaves a team's environment.

Bringing PyTorch Monarch to AMD GPUs (1 minute read)

PyTorch brought Monarch, its single-controller distributed training runtime, to AMD Instinct GPUs with ROCm, extending the actor-based programming model beyond CUDA. Monarch orchestrates entire GPU clusters from one Python program and dynamically recovers from node failures without restarting the full job, enabling elastic fault-tolerant training after prior work hit 96.16% scaling efficiency on a 1024-GPU MI325 cluster.
