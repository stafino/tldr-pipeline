The Economic Benefit of Refactoring (1 minute read)

Martin Fowler let agents write a 150,000-line application (mostly Rust) without reviewing the code, then studied what happened when the data access layer ballooned to a single 17,155-line file. He argues the economic case for refactoring an agentic codebase is that spending tokens now to restructure code lowers the token cost of every future feature. Because agents never learn between sessions, he could measure this cleanly, prompting a fresh agent to make the same change after each refactoring stage.
