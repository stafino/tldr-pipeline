2x, not 10x: coding with LLMs in 2026 (5 minute read)

The author argues that LLMs deliver roughly a 2x coding productivity gain, not 10x, and that further model improvements will matter less than they have so far. His hypothesis is that 2026 adoption came from models crossing a reliability threshold that lets them run in automated feedback loops toward explicit, verifiable acceptance criteria. Beyond that threshold, questions like whether code is maintainable or documentation is complete remain outside what LLMs can reliably predict, so he uses them for rough drafts he then reworks heavily.

Two independent teams solved the same quantum cryptography problem using GPT-5.6 Sol Ultra and filed papers just 3 hours apart, exposing a growing gap in how scientific credit is assigned. As LLMs compress research timelines from months to hours, near-simultaneous discovery becomes routine, and priority conventions built for slower science struggle to determine who gets credited for what.

Don't be a meat proxy (1 minute read)

The author argues against acting as a "meat proxy," relaying AI output verbatim in Slack threads, pull request feedback, or code review instead of engaging directly. Pasting a raw Claude response adds no value, since the recipient could query the model themselves with better context control. The real contribution is reading, understanding, and validating the output, then responding in your own words as evidence that you did that work.

SkillSpector is an open-source scanner from NVIDIA that reads an AI agent skill from a directory, zip, SKILL.md, or Git URL and returns findings, a risk score, and an install recommendation. A fast static pass walks the AST for exec and subprocess calls, tracks tainted data to network sinks, and runs 64 detection patterns for prompt injection, credential access, and typosquatted dependencies, with an optional LLM pass that reaches roughly 87% precision.

Hugging Face Diffusers Flaws Could Let Model Repositories Execute Arbitrary Code (1 minute read)

Zafran Labs disclosed FaceHugger, three high-severity flaws in Hugging Face's Diffusers library that let crafted model repositories bypass the trust_remote_code safeguard and execute arbitrary code on machines loading them. Each variant stems from a Time-of-Check to Time-of-Use gap where the trust gate runs only against the first of two non-atomic download requests, exposing a package downloaded over 8.1 million times in July 2026.

Explorative modeling: Train on the best of K guesses (1 minute read)

Explorative Modeling is a new pretraining paradigm that trains generative models on the best of K sampled guesses, addressing the problem that a single prediction collapses to the blurry average of many valid outputs. The authors report that Explorative Models reach 6.2x sample efficiency, 4.1x FLOP efficiency, and, as end-to-end generators, match diffusion on control tasks with up to 256x less inference compute.
