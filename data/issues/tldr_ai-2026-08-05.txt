Cross-Model KV Cache Transfer in LLM Families: A Closed-Form Linear Mapping for Prefill Reuse (1 minute read)

This paper introduces cross-model KV cache transfer, letting a receiving model reuse a source model's KV cache when swapping between different-sized models in a family, skipping prefill entirely. A closed-form per-head ridge mapper, fit on 500 calibration sequences, retains 73-98% of standalone-prefill accuracy on four of six model pairs and runs 2.7-25x faster than re-prefilling, with a nonlinear MLP recovering the two pairs that degrade.

Oilbird: Training-Free Speculative Decoding with Keys the Verifier Already Computes (1 minute read)

Oilbird is a training-free speculative decoding method that adds a semantic draft source, re-keying the existing context pool by the hidden states the verifier already computed at each committed token. Across ten benchmarks it lifts accepted draft length by 24-29% and reaches 4.4x autoregressive decoding speed on API-Bank, versus 3.9x for the strongest training-free baseline and 2.0x for EAGLE-3.

WorldCup Arena: Prospective, Leakage-Free Evaluation of Frontier LLMs on a Live Tournament (1 minute read)

This paper introduces WorldCup Arena, a leakage-free forecasting benchmark that asked six frontier LLMs to predict all 104 matches of the 2026 FIFA World Cup before each kickoff, producing 4,494 scored predictions with no answers available at question time. The models averaged 63.9% on match outcomes, roughly matching the bookmaker's favorite, agreed with each other more than they were right, and lost accuracy on the closest fixtures where the most information exists.

Omega-S: A Functional Resilience Index for LLM Fine-Tuning (1 minute read)

Omega-S is a drop-in fine-tuning penalty that reduces catastrophic forgetting using only the weight matrix, requiring no previous-task data, Fisher matrix, or stored old weights while adding under 4% per step. On Llama-3-8B with LoRA tuned from code to prose, it lifted HumanEval retention from 62.9% to 84.1% and beat tuned weight decay on all 10 seeds and EWC on 8 of 10.

LiveEvalBench: Toward Open-World Evaluation for Web Generation (1 minute read)

LiveEvalBench is an automated framework that reframes web-generation evaluation as an agentic, adaptive process, using a Build Engineer, Code Engineer, and UI Tester to gather evidence from deployment and code inspection through browser-based interaction. An adaptive protocol pairs shared rubrics for cross-model comparability with implementation-grounded criteria per artifact, and the authors report close alignment with human expert judgment across real-world scenarios.

Resume Means Resume: A Machine-Checked Conformance Contract for Checkpoint, Interrupt, and Resume Semantics in Workflow Persistence Layers (1 minute read)

This paper introduces the RESUME CONTRACT, six machine-checkable properties for how workflow persistence layers should handle effects that already fired before an interrupt or crash, verified with a TLA+ model exhaustive to 7.4 million states. Testing at pinned releases found LangGraph 1.2.9, CrewAI 1.15.2, and pydantic-graph all violate their own stated semantics, and the authors ship REMIT, a Verus-verified reference sequencer that repairs the failing cases including duplicate effects under concurrent resume.

Test-Time Scaling in Reasoning LLMs: Inference Regimes, Evaluation, and Reproducibility (1 minute read)

This paper develops a systematic account of test-time scaling in reasoning LLMs, formalizing it as budgeted inference over an autoregressive model's prefix tree and distinguishing three regimes: single-trajectory sequential scaling, leaf-level scaling with terminal reduction, and prefix-level scaling. The authors argue that reporting accuracy without the inference protocol makes results incomparable, prescribe protocol-matched reporting of compute and uncertainty, and release over 2 billion full reasoning traces with verifier and token-level signals.

Sensitivity, Causality, and Repair Dissociate: A Layer-Wise Analysis of Perturbation Robustness and Its Scaling (1 minute read)

This paper shows that three ways of locating which layer causes a language model to fail on perturbed input (typos, OCR noise, homophones) dissociate: sensitivity, causality, and repair capacity produce different layer maps. Across a five-model panel, the authors find that placing repair adapters at diagnostic-flagged early layers is the worst choice, since it breaks intact downstream computation, and recommend a default-deepest placement rule instead.

Efficient Knowledge Distillation for LLMs: Offline Top-K Logits and a Fused Chunked KL Loss (1 minute read)

This paper presents two systems techniques for making LLM knowledge distillation cheaper. Offline KD caches the teacher's top-K logits once and trains the student against the cache, matching online distillation's loss while running about 29% faster per iteration and reaching 41% higher throughput on a single H200, and a fused chunked KL loss keeps peak memory linear in sequence length to enable training at 32,768-token context on one GPU.
