Comparative Approaches to Agent Retrieval over Large Skill Libraries (1 minute read)

This paper compares two retrieval systems for agents choosing among a library of 690 skills: a hybrid lexical plus dense-embedding ranker for on-demand loading, and a typed knowledge graph encoding prerequisites, data flow, and ordering. The ranker hits the correct skill in its top five 73.5% of the time, while the graph performs 11.2 points worse at matched token budget because 98.6% of its typed edges connect skills the ranker already surfaced together.

Muon on the Stiefel Manifold Admits an Exact Closed-Form Update (1 minute read)

The authors use this result to build Skewon, an algorithm for orthogonality-constrained optimization, and establish first-order convergence guarantees in the smooth non-convex setting.

Learning When to Trust via Selective Context Preference Optimization (1 minute read)

This paper reframes robustness to misleading context as selective trust and introduces MIST, a human-annotated benchmark that presents each item under clean, misleading, correct-context, and irrelevant-context conditions. Its SCOPE method mines clean-correct/misleading-wrong failures and runs DPO over matched pairs balanced across all four conditions, cutting how often misleading signals flip correct answers while preserving accuracy on clean input.

AI-Assisted HTTP Terminator Finds Novel HTTP Desync Techniques and Apache Zero-Day (1 minute read)

PortSwigger detailed HTTP Terminator, an AI-assisted research system built by James Kettle that split 138 HTTP and SMTP RFCs into 15,000 fragments to generate 30,000 candidate desync vectors, finding roughly 700 vulnerable targets across banks, government infrastructure, and an airport. The work produced new request-smuggling triggers, including a "dangling-byte" technique that eliminates the race condition making response queue poisoning unreliable, plus an Apache Traffic Server zero-day tracked as CVE-2026-63078.

Beyond Top-K: Replacing Black-Box Retrieval with Interpretable Agentic Operations (1 minute read)

This paper introduces READ (Reliable Embedding-free Agentic Document-search), which replaces top-k dense retrieval with an agent that reads raw documents through three deterministic Model Context Protocol operations: normalized lexical search, structural navigation, and bounded span reads. On 51 verified questions over a 780-page financial report, READ answered 58.8% correctly versus 15.7% for dense retrieval, though the authors note BM25 is statistically indistinguishable, isolating the gain to embedding-free retrieval rather than agentic iteration.

HarnessOpt-Bench: Evaluating LLMs at Harness Optimization (1 minute read)

HarnessOpt-Bench is a benchmark that measures how well frontier LLMs optimize agent harnesses, the prompts, tools, control flow, and orchestration code surrounding a model, under expensive and stochastic evaluation with a fixed target-evaluation budget. Across 111 scored runs evaluating 5 frontier models over 4 downstream tasks, the authors found that optimizer models separate more than the coding harnesses they act through, native harnesses are not consistently better, and gains vary widely across tasks and seed regimes.

On-Policy Self-Distillation without Any Supervision (1 minute read)

This paper introduces U-OPSD, an unsupervised on-policy self-distillation method that post-trains LLMs using only their own generations, with no ground-truth signals, environmental feedback, or larger teacher models. It builds a pseudo-solution via majority vote, then distills it into prefixes of the model's longest incorrect completion, improving Qwen3 base models by 8.5% at 4B and 10.7% at 8B across math benchmarks while matching or beating supervised methods like OPSD and GRPO.

MACRO: Markov Chain Routing of Transformer Layers (1 minute read)

MACRO is a framework that learns task-specific execution routes through a frozen LLM's transformer layers, modeling layer routing as a context-dependent Markov policy that supports skip, repeat, and residual hidden-state addition operations without updating any weights. It delivers a +5.0% average accuracy gain over unrouted baselines and beats the prior best dynamic router, Dr. LLM, by +7.2% while cutting route-search time 9.4x, from 14.8 to 1.6 hours.

DCAS: Decoupling CLI Agent Scaffolding to Internalize Planning across Scaffolds (1 minute read)

This paper introduces DCAS (Decoupling CLI Agent Scaffolding), an interception layer that routes API traffic between any CLI coding-agent scaffold and any backend model without modifying the scaffold, enabling cross-scaffold evaluation and planning-aware trajectory collection. The authors show that models fine-tuned on OpenHands trajectories degrade under other scaffolds, and that a model trained on a small set of DCAS-collected planning-aware trajectories improves consistently across non-training scaffolds.
