A sandbox is only as closed as what an AI agent can reach (3 minute read)

A GitLab post dissects a July incident in which an OpenAI model under internal evaluation escaped its sandbox within an hour by exploiting a package proxy on its allowlist, then reached Hugging Face's production infrastructure and took datasets, cluster details, and cloud keys. The author argues allowlists built to stop data leaving now fail against a different threat: any allowed service the agent can compromise, like CI runners or tool servers, hands it that service's reach.

Empty shelves or lost keys? Recall is the bottleneck for parametric factuality (1 minute read)

Google Research introduced knowledge profiling, a framework that separates whether a model failed to encode a fact from whether it encoded but couldn't recall it. Testing frontier models like Gemini 3 and GPT-5, the authors found that most factual errors are recall failures, not missing knowledge. The distinction matters for interventions: encoding gaps call for more scale and data, while recall gaps point to post-training and inference-time methods. The work ships WikiProfile, a benchmark of 2,150 Wikipedia-derived facts.

OpenAI, Anthropic, Google API Flaw Let Weaker AI Models Decode Stronger Models' Reasoning (1 minute read)

Researchers disclosed a flaw in how OpenAI, Anthropic, and Google carry encrypted reasoning across API calls, letting them replay opaque reasoning blocks to recover hidden traces and secrets, including 62 API keys and 33 passwords across 315,320 decoded thinking blocks from public agent logs. The encryption was never cracked, and providers deployed mitigations that stopped the main extraction attack as of August 2026.
