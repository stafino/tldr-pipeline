Don't be a meat proxy (1 minute read)

The author argues against acting as a "meat proxy," relaying AI output verbatim in Slack threads, pull request feedback, or code review instead of engaging directly. Pasting a raw Claude response adds no value, since the recipient could query the model themselves with better context control. The real contribution is reading, understanding, and validating the output, then responding in your own words as evidence that you did that work.

The Agent Access Model (1 minute read)

Cloudflare's paper proposes the Agent Access Model (AAM), an access framework for software agents that BeyondCorp-style Zero Trust does not cover because it assumes a human working at human speed. Rather than making each access decision smarter, AAM shrinks the agent's capability ceiling per task-scoped run so there is less to judge, addressing controls that fail quietly by granting too much and trusting for too long.
