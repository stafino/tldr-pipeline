The borderless Lakehouse: Bring AWS, Databricks and Snowflake data to your AI agents (2 minute read)

Google Cloud introduced enhancements to its borderless Lakehouse, adding Iceberg REST catalog federation (now in preview) for AWS Glue, Databricks Unity, and Snowflake Horizon so BigQuery and Managed Spark can query those tables in place without copying files. The pitch is zero-copy, bidirectional access across clouds plus direct SAP, Salesforce, and Workday queries, positioning BigQuery as one more Iceberg compute engine over data that stays where it lives.

Snowflake launches AI agent governance layer to track activity, control costs (2 minute read)

Snowflake launched Cortex AI Gateway, a runtime control plane that tracks agent actions, enforces Horizon Catalog policies, and caps token and resource spend across first- and third-party models, tools, and MCP servers. The layer, built on May's Natoma acquisition, folds FinOps and governance into where enterprise data is already governed, giving CIOs one audit trail for who authorized each agent and what it consumed as consumption-based AI pricing spreads.

After rewriting SQLite in Rust, Turso turns its sights on Postgres (1 minute read)

Turso, which rebuilt SQLite from scratch in Rust as an open-source rewrite, is now extending that engine to speak the Postgres wire protocol and add server-grade features like concurrent writes and replication. The move pushes Turso beyond embedded, single-file use cases into territory currently owned by Postgres, betting that a memory-safe rewrite can win teams weighing both an embedded database and a full client-server one.

Automate data monitoring and root-cause analysis with Looker Agentic Workflows (2 minute read)

Google added Looker Agentic Workflows in preview for version 26.08, using background agents to turn natural-language prompts like "notify me if average order value exceeds $1,000" into continuous metric monitors that run Key Driver Analysis and deliver root-cause summaries to Slack or email. The move pushes BI past threshold alerts into automated diagnosis, with admin-level oversight to review or disable workflows across the instance.
