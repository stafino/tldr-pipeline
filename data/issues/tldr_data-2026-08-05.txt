SieveIVF: Threshold-Aware IVF Execution for Large-Scale Training Data Deduplication (1 minute read)

SieveIVF is a threshold-aware IVF search executor that stops probing partitions once W consecutive searches turn up no candidate above the similarity threshold, exploiting the fact that qualifying duplicates surface early. Built into Lance, it runs 4.1-8.4x faster than fixed-probe IVF on 10M and 100M embedding dedup workloads, at a top-10 recall cost of 0.03-2.29 points. The takeaway is that an application predicate can steer IVF work allocation without touching the index.

This is why we can't have nice things (1 minute read)

The author revisits his 2023 prediction that AI would mirror cloud computing, with a handful of providers like OpenAI and Anthropic becoming invisible infrastructure that every product quietly calls through an API. The essay questions whether that clean analogy holds, noting that unlike AWS or Snowflake, model providers face commoditized outputs, thin switching costs, and no clear path to the durable margins cloud vendors enjoy. For data teams betting their stack on a single model API, the open question is whether any of these companies works as a business yet.

RAG-Stack: Co-Optimizing RAG Serving Performance and Quality (1 minute read)

This paper introduces RAG-Stack, a framework for finding the quality-performance Pareto frontier across RAG configuration choices like retrieval indexes, model selection, and how models invoke retrieval. Rather than deploying every candidate, it uses a design-space exploration algorithm, a workload abstraction, and a performance model to predict optimal deployments and transfer a known frontier to new serving hardware. It covers 52.5% to 153.2% more of the normalized quality-performance space than existing configuration-search methods over the same iteration budget.

Why Large Language Models Fail at Tabular Prediction (1 minute read)

This paper isolates why frontier LLMs keep losing to fifty-year-old baselines on tabular prediction, testing five hypotheses in a single inference pass with no tools or fine-tuning. Format, tokenization, noise, and batch size all get falsified. Dimensionality is the culprit: across 31 datasets, the LLM is the only method of nine whose accuracy drops as dimensions grow, behaving like a local distance-based classifier in 2D but degrading in a way no noise-corrupted classical model reproduces.

Uplifting the Superpowers of Worst-Case-Optimal Join Algorithms (1 minute read)

This paper extends worst-case-optimal join algorithms to handle filters natively, rather than applying selections before or after processing Basic Graph Patterns as most SPARQL and GQL engines do. The authors build the technique into Ring, a compact graph index that resolves patterns in almost no space beyond the graph itself, extend it to property graphs, and report that it beats baseline systems in experiments while staying compact.

Evaluating LLMs in Database Scenarios: A Lifecycle Benchmark for Assessing Their Potential in Core Database Tasks (1 minute read)

DBLifeBench is the first benchmark to test LLMs across the full database lifecycle: design, implementation, operation, debugging, and maintenance, rather than the usual Text-to-SQL slice. The headline finding is that specialized Text-to-SQL models hit "catastrophic forgetting" on non-coding phases like schema design and maintenance, while general-purpose models stay balanced across all five. The takeaway for teams eyeing LLM-driven DBA work is that a fine-tuned SQL model is not a full-stack replacement.

Stateful Governance for Concurrent Agentic Systems (1 minute read)

This paper tackles governance for AI agents that execute real effects like refunds, inventory holds, and cloud provisioning, where a request-time authorization can go stale before the effect commits. The authors define policy-state serializability, requiring every committed effect to be authorized against the policy state immediately before it occurs, and build Provenact, a PostgreSQL-backed runtime that keeps policies as reviewable programs. In tests, it blocked stale authorizations over shared budgets and inventory that request-context baselines let through.
