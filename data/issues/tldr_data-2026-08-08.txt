Metabase Zero-Day Exploited in Wild Allows Admin Access Without Authentication (1 minute read)

Metabase disclosed a maximum-severity zero-day (CVSS 10.0) in versions 1.58 and above that lets an unauthenticated remote attacker inject SQL into the application database and gain admin access, exposing stored credentials for every connected data warehouse. Metabase Cloud is already patched, but self-hosted teams must upgrade immediately, block the /api/session/reset_password endpoint as a stopgap, and rotate all connected-database credentials since instances have been compromised in the wild.

Metabase SQLi zero-day exploited in customer data-theft attacks (1 minute read)

Metabase disclosed a zero-day SQL injection flaw, rated CVSS 10.0 and actively exploited, that let unauthenticated attackers gain administrator access to instances running versions 1.58 and above, breaching Framework and Tally among others. Cloud customers are already patched, but self-hosted teams must upgrade to fixed releases immediately, then rotate connected-database credentials and revoke sessions since attackers could read and export any data reachable through those connections.
