Guided Table Retrieval for Structured Data Search (1 minute read)

This paper introduces guided table retrieval, a four-phase pipeline for answering natural language questions over structured databases by identifying relevant tables and inferring their joins. Instead of leaning on a single end-to-end LLM, it splits the work into deterministic hash-based grounding, join-graph exploration, LLM disambiguation, and algorithmic merging into minimal join trees. The authors report 94% precision on BIRD-DEV and 70% on the enterprise-scale BEAVER benchmark, outputting exact join trees that downstream query compilers can consume directly.

Breaking the WAL (1 minute read)

Antithesis reproduced SQLite's WAL-Reset bug in 15 minutes using a generic concurrent write-and-checkpoint workload and standard database assertions like "no lost committed writes" and "database not corrupt." The data race had gone undetected since 2010 because it never reproduced organically. The lesson for data teams: the simplest workloads often surface the hardest bugs, and deterministic simulation testing can catch races that manual reproduction never will.

An Extended Tutorial and Vocabulary for Relational Language Design in an Era of AI-Assisted Query Generation (1 minute read)

This 3-hour tutorial paper argues that as queries are increasingly written by machines and read by humans, the relevant question for relational language design is no longer expressive power but readability and revisability across SQL, dataframe, pipeline, graph, and functional notations. Using Abstract Relational Calculus and Relational Diagrams as reference representations, the authors build a vocabulary for comparing how languages express the same intent, extending it to recursive path queries, nested relations, and problems beyond PTIME.

Plaintext Recovery Against Post-Filtering Access Control (1 minute read)

This paper shows that post-filtering access control in databases leaks far more than prior work assumed. Row- and document-level security let untrusted queries run over all data before redacting private rows, and the authors turn that into full plaintext recovery. They exploit RLS timing side-channels in PostgreSQL and DLS scoring in Elasticsearch, using range, prefix, and conjunctive predicates to binary-search unknown values into complete records and approximate documents.

Enabling Differentiated QoS Degradation for Replicated Databases under Failures (1 minute read)

This paper tackles what happens to a replicated database when you can't just spin up replacement replicas after a failure. The authors present PLB, a PostgreSQL JDBC middleware load balancer that reassigns healthy replicas into Premium, Mixed, and Freemium roles under fail-stop failures, keeping the pool shared while preserving service-class differentiation. Against shared round-robin routing, it holds 26-28 more percentage points of median Premium goodput and cuts Premium p95 latency by 18.2%.

Reverse Migration of Cloud Applications to On-premises (1 minute read)

Diel, a reverse-migration tool from the Tursio team, automates moving cloud applications back to on-premises environments for regulated industries that can't deploy in the cloud. Time to Move on: Querying without Nulls and Bags (1 minute read)

This paper argues that SQL's tolerance of nulls and bags (duplicate-laden, non-normalized relations) is an avoidable mistake, not a necessary evil. Drawing on their work building Rel, a language for end-to-end relational programming, the authors show a query language can run on fully normalized relations with set semantics, dropping both the "billion dollar mistake" of nulls and Codd's corrupted relations. They contend the usual justifications for keeping them collapse under scrutiny, and outline what a null-free, set-based language enables.
