Postgres LISTEN/NOTIFY actually scales (1 minute read)

The authors optimized Postgres LISTEN/NOTIFY-backed streams to sustain 60K writes per second on a single server with millisecond latency, refuting the widely cited claim that the feature does not scale. The bottleneck was the global exclusive lock Postgres takes during every NOTIFY, which capped a naive per-chunk trigger implementation at 2.9K writes per second before the redesign batched notifications to avoid it.

The post covers where the primitive shines for building agents and where it falls short, drawing on several months of building almost exclusively on DOs.

I Inspected My Take-Home Interview Project. It Was a Whole Operation (1 minute read)

A developer accepted a take-home assignment from a LinkedIn recruiter and found a malicious payload hidden in the project's `.git/hooks` directory, disguised behind a clean `requirements.txt` and a legitimate-looking FastAPI codebase. Running `tree -a` surfaced the operation that a casual clone-and-run would have executed silently, a reminder that git hooks fire on standard commands and warrant inspection before you touch an untrusted repo.

Characterizing Metastable Faults and Failures (5 minute read)

This paper offers the first analytical causal account of metastable failures, the self-sustaining goodput collapse that persists via internal feedback loops like retries and queues even after the trigger disappears. It frames a metastable fault as a "sin of composition" between individually stable components wired into a destructive cycle and ties recovery to scheduling, though the author disputes its claim that metastable fault tolerance can be designed through local pairwise reasoning alone.

How MVCC and Transactions Work in RocksDB (5 minute read)

This post explains how RocksDB layers multi-version concurrency control on top of its LSM-tree, where immutable memtables and SST files already keep multiple versions of every key so writers never modify data in-place. It walks through the missing half, showing how snapshots give readers a consistent point-in-time view, how compaction garbage-collects stale versions, and how atomic updates and transactions are built on those primitives.

Aurora DSQL: Scalable, Multi-Region OLTP (5 minute read)

This paper describes Amazon's Aurora DSQL, a distributed SQL database that disaggregates the transaction, journal, and storage layers to scale writes and reads independently while keeping PostgreSQL compatibility. It relies on optimistic concurrency control with a single commit-time conflict check, and provides strongly consistent active-active multi-region deployments backed by a quorum-replicated journal rather than synchronous cross-region locking.

Getting Clean Text Out of PDF, DOCX, and HTML (3 minute read)

The post argues that text extraction, not generation, is the real engineering bottleneck for any pipeline that turns documents into audio, summaries, or embeddings, since a PDF only stores glyph coordinates with no notion of paragraphs or reading order. It walks through geometric column detection that projects text blocks onto the x-axis to find sustained gaps, run per page rather than per document, plus stripping running heads and page numbers that otherwise splice mid-sentence.

Fil-C: Garbage In, Memory Safety Out [video] (1 minute read)

Fil-C is a memory-safe implementation of C and C++ that compiles existing code without source changes, using garbage collection and pointer capabilities to eliminate use-after-free and buffer overflows. The talk covers how it enforces safety at runtime and the performance cost, which currently runs several times slower than standard C but removes an entire class of memory-corruption vulnerabilities.

New pip flag fixes longstanding Python frustration (1 minute read)

pip 26.2 adds `pip install --only-deps`, which installs a package's runtime dependencies without installing the package itself, closing a years-old gap that previously forced manual dependency extraction or full builds. The flag covers runtime requirements but not build dependencies, and mirrors behavior already available in third-party tools like uv's `uv sync --no-install-project`. It ships by the end of July 2026.

G# language for .NET borrows from Go, Kotlin, and Swift (1 minute read)

G# is a new pre-1.0 language for .NET that brings Go, Kotlin, and Swift ergonomics to the CLR, compiling to managed PE assemblies that work with the standard .NET toolchain. It offers Go-style keywords like func, structs, slices, channels, and select alongside nullable flow, structured concurrency, and direct calls into any BCL, NuGet, or first-party .NET type, with a VS Code extension already shipping syntax highlighting and language server support.

Cruller: Bun's Zig Runtime, Continued on Zig 0.16 (1 minute read)

Cruller is a fork of the last Zig-based Bun release, stripped to just the pieces needed to run pre-built production JavaScript servers and ported to vanilla Zig 0.16. It keeps JavaScriptCore, Bun.serve, HTTP/1-3, WebSockets, fetch, and the module resolver while dropping the package manager, bundler, transpiler, test runner, and N-API, yielding an 18% smaller runtime (73.0 MiB vs Bun 1.3.14's 88.5 MiB) at roughly benchmark parity on Linux x64.

The case for a cooldown: Why Dependabot now waits before issuing version updates (1 minute read)

Dependabot now waits at least three days after a release is published before opening non-security version update pull requests, a default cooldown you can override in dependabot.yml. The change targets supply chain attacks like September 2025's compromise of chalk, debug, and other packages, where poisoned versions were live for roughly two hours, long enough for update tooling to pull them into build pipelines before anyone caught the malware.
