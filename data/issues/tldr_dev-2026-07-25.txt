One Cache Miss, Fifty Database Calls (3 minute read)

The post demonstrates cache stampede, where .NET's `IMemoryCache.GetOrCreateAsync` fires a fresh factory for every concurrent miss on the same key, turning 50 simultaneous requests against a cold cache into 50 identical 200ms database queries despite a 99% hit rate. Swapping in `HybridCache` deduplicates callers per key so the first request runs the query and the other 49 await that same task, collapsing the burst to a single database call.
