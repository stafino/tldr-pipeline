Characterizing Metastable Faults and Failures (5 minute read)

This paper offers the first analytical causal account of metastable failures, the self-sustaining goodput collapse that persists via internal feedback loops like retries and queues even after the trigger disappears. It frames a metastable fault as a "sin of composition" between individually stable components wired into a destructive cycle and ties recovery to scheduling, though the author disputes its claim that metastable fault tolerance can be designed through local pairwise reasoning alone.

How MVCC and Transactions Work in RocksDB (5 minute read)

This post explains how RocksDB layers multi-version concurrency control on top of its LSM-tree, where immutable memtables and SST files already keep multiple versions of every key so writers never modify data in-place. It walks through the missing half, showing how snapshots give readers a consistent point-in-time view, how compaction garbage-collects stale versions, and how atomic updates and transactions are built on those primitives.

Introduction to Data-Oriented Design [pdf] (1 minute read)

This paper introduces data-oriented design, an approach that structures code around how data is laid out in memory rather than around objects and their behavior. It walks through cache-friendly patterns like struct-of-arrays layouts and hot/cold data splitting, showing how organizing for access patterns cuts cache misses and speeds up tight loops in games and other performance-critical systems.

Aurora DSQL: Scalable, Multi-Region OLTP (5 minute read)

This paper describes Amazon's Aurora DSQL, a distributed SQL database that disaggregates the transaction, journal, and storage layers to scale writes and reads independently while keeping PostgreSQL compatibility. It relies on optimistic concurrency control with a single commit-time conflict check, and provides strongly consistent active-active multi-region deployments backed by a quorum-replicated journal rather than synchronous cross-region locking.

Scriptc by Vercel: TypeScript-to-Native compiler, no JavaScript engine in binary (1 minute read)

Scriptc compiles ordinary TypeScript into self-contained native binaries with no Node, V8, or JavaScript engine linked in, producing executables like a 178KB fib binary with roughly 2ms startup and no code changes or annotations required. Code that can't compile statically either runs through an optional embedded QuickJS engine under `--dynamic` or fails with a specific error code and code frame, and a `scriptc coverage` command reports construct-by-construct what compiles.

Ruff v0.16.0 – Significant new updates – 413 default rules up from 59 (1 minute read)

Ruff v0.16.0 now enables 413 lint rules by default, up from 59, pulling in flake8-bugbear, pyupgrade, and RUF rules that catch syntax errors and immediate runtime bugs without any configuration. The release also stabilizes formatting for Python code blocks embedded in Markdown and Quarto files, and users who want the old behavior can revert with `select = ["E4", "E7", "E9", "F"]`.

How AST-grep Rewrote Tree-sitter in Rust and Made It 30% Faster (1 minute read)

ast-grep rewrote Tree-sitter's C core in Rust, with AI generating the code, producing a parser that runs 30% faster and an end-to-end ast-grep workload about 22% faster. The tradeoff is scope and memory: the new runtime drops WebAssembly language loading and incremental tree reuse to target AI agents that analyze full file snapshots, and uses roughly 8 MiB more RSS per run.

Running a 28.9M parameter LLM on an $8 microcontroller (1 minute read)

A developer ran a 28.9M parameter LLM entirely on-device on an ESP32-S3, an $8 microcontroller with just 512KB of SRAM, generating text at roughly 9 tokens per second with nothing sent to a server. The build fits a model 100x larger than prior attempts by keeping the 25M-row embedding table in slow flash and reading only the ~450 bytes each token needs, an application of Google's Gemma Per-Layer Embeddings to microcontroller memory layout.

Bringing PyTorch Monarch to AMD GPUs (1 minute read)

PyTorch Monarch now runs on AMD Instinct GPUs with ROCm, extending its single-controller, actor-based runtime for distributed training beyond CUDA. The port brings elastic fault tolerance that lets healthy nodes keep training while failed nodes recover and rejoin, avoiding the full-job restart that periodic checkpointing forces after a single GPU memory error, network partition, or node crash.

Show HN: CheapSecurity – Lightweight, Self-Hosted CCTV for Linux SBCs (1 minute read)

CheapSecurity is a self-hosted CCTV stack for Linux single-board computers like the Raspberry Pi and Orange Pi, running motion detection via OpenCV frame differencing against a standard USB webcam. It streams live MJPEG to a web dashboard, records with a pre-motion buffer, pushes Telegram and email alerts on motion, and handles retention cleanup by age or disk pressure, all under AGPLv3 with no cloud dependency.

I ported a knowledge-format (OKF) library to zero-dependency .NET — here's what I learned (3 minute read)

OKF4net is a zero-dependency .NET (C#, net10.0) implementation of Google's Open Knowledge Format v0.2, which stores a knowledge base as a directory tree of markdown files with YAML frontmatter that agents read via ReadFile and humans diff, grep, and review in a PR. The port replaced an earlier Rust implementation and is verified in CI against five byte-exact golden CLI captures (validate, info, graph --dot, fmt, index) taken from the original binary.

Fable found a 15-30% memory efficiency improvement in Turbopack, Next.js's Rust-based bundler, and documented the fix in a thread walking through the profiling and allocation changes.
