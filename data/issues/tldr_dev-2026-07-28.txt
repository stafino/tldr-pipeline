Zig's Incremental Compilation Internals (1 minute read)

A Zig core team member details how the compiler's incremental compilation works, detecting which individual functions and declarations changed since the last build, recompiling only that code, and patching the new bytes directly into the output binary. The result cuts rebuilds on real applications from a 5-second cold build to 50-70ms, though it depends on linker features that land in tagged releases only with Zig 0.17.0.

How Do I Profile eBPF Code? (1 minute read)

The author builds a minimal C harness that calls SYS_openat directly instead of the libc wrapper, prefaults and mlocks memory to eliminate page faults from the loop, discards the first 10% as warmup, and captures p50/p99 open latency before and after attaching the hook, then uses perf with resolved symbols to locate the bottleneck.

The Orchestrator's Tax (1 minute read)

Martin Fowler argues that subagents in long-running multi-agent work should be justified by what they keep out of the orchestrator's context, not by parallelism or time saved. Drawing from one real Claude Code incident, he found the biggest cost came not from running four subagents but from the orchestrator reconciling their out-of-order results, and proposes treating delegation as a tool for protecting the orchestrator's working memory with explicit rules for when to offload reasoning.

MCP just got its biggest update ever — here’s what changes for AI agents (2 minute read)

The Model Context Protocol shipped its largest revision since launch, finalizing a fully stateless architecture that lets MCP servers run behind standard load balancers instead of requiring sticky routing or a shared session store. The release, now stewarded by the Linux Foundation's Agentic AI Foundation, also hardens authentication, adds a 12-month deprecation policy, and graduates server-rendered interfaces and long-running async tasks into official protocol extensions.

Biggest ever MCP update brings metadata, cybersecurity enhancements (1 minute read)

The Model Context Protocol shipped its largest update since launching, replacing the handshake used to exchange request metadata with a stateless protocol core that packages metadata directly into requests. Removing the single-server dependency makes MCP applications easier to scale during traffic spikes and simpler to recover after outages, and the release also strengthens the authorization mechanism governing agent access to external systems.

MCP 2026-07-28 Specification: transport going stateless (1 minute read)

The 2026-07-28 Model Context Protocol specification makes the protocol core stateless, turning MCP from a bidirectional stateful connection into self-describing request/response calls that any instance can serve behind a round-robin load balancer. The release also adds header-based routing via Mcp-Method and Mcp-Name, Multi Round-Trip Requests to replace open bidirectional streams, cacheable list responses, RFC 9207 authorization hardening, and updated Tier 1 SDKs.

Uv 0.12.0 (1 minute read)

uv 0.12.0 is the first release since March to bundle breaking changes, most notably making `uv init` declare a `uv_build` build system and a `src/` layout by default so new projects are packaged and importable out of the box.
