Don’t stop early: Case-folding source code at memory speed (1 minute read)

GitHub open-sourced casefold, a Rust crate that case-folds source code at over 45 GiB/s per core by sweeping the whole buffer branch-free instead of stopping at the first non-ASCII byte. The post explains why folding differs from lowercasing, why removing the ASCII early-exit optimization made the hot path faster, and how byte-space arithmetic handles the simple 1-to-1 Unicode folds that power Blackbird's 480TB code search index.

Algorithms on billion-scale graph using 10GB RAM: I love DataFusion (1 minute read)

The author implemented graph map-reduce over Apache DataFusion, offloading to disk and relying on bulk scans and sort-merge joins instead of random access, letting DataFusion handle spillover, planning, and execution. The result computes PageRank on a one-billion-edge graph in 5GB of RAM and finds weakly connected components on two billion edges in 10GB, with remaining rough edges around FairSpillPool deadlocks and getting SMJ to reuse on-disk pre-sorting.

PostgreSQL's MVCC Is Bad: So Is Everyone Else's (5 minute read)

The author argues that PostgreSQL's much-criticized MVCC costs, including table bloat, write amplification, and VACUUM babysitting, all trace to four concrete design choices rather than a defect, and reproduces each one on a live PostgreSQL 19 beta2 instance. Every other engine answers the same four questions differently, shifting the bill to the writer, tempdb, the cache, or the compactor, and all of them break when a transaction stays open too long.

Silent Data Loss in Celery + RabbitMQ on Azure Container Apps: A Queue Registration Post-Mortem (2 minute read)

A FastAPI, Celery, and RabbitMQ system on Azure Container Apps silently dropped every write for a subset of operations, returning 202 Accepted while a stale queue registration meant no worker was actually consuming the messages. The author traces the multi-day hunt to a mismatch between the container entry point and the platform resource config, and shows why healthy containers, a healthy broker, and correct code produced no error anywhere in the stack.

Go 1.27 Interactive Tour (1 minute read)

Go 1.27's headline feature lets method declarations carry their own type parameters independent of the receiver, so a generic operation like `Map` that transforms `Box[int]` into `Box[string]` can finally live as a method instead of a package-level function. This VictoriaMetrics tour walks the change with runnable examples, and flags the key restriction that interfaces still can't declare generic methods, so a generic method can't satisfy an interface.

Golang proposal: container/: generic collection types (1 minute read)

Go's Collections working group proposed a set of standard-library collection types for Go 1.28, including a hash-based Map that accepts custom hash functions, ordered maps and sets backed by binary trees, and a general set type to replace the map[T]struct{} convention. The APIs build on generics from Go 1.18 and iterators from Go 1.23, aiming to give library-defined containers the same ergonomics as built-in slices and maps.

qm – Multiplayer agent harness for work (1 minute read)

QM is an open-source multiplayer agent harness that gives each employee an isolated workspace with its own scoped memory, files, permissions, crons, and durable sandbox, accessible from both Slack and a web app. Rather than binding a deployment to one vendor, it lets teams pick and switch between harnesses and models including Pi, OpenCode, Codex, and Claude Code, all driving the same headless core backed by Postgres.

Flint: A Visualization Language for the AI Era (1 minute read)

Flint compiles a single compact chart spec into native output for Vega-Lite, ECharts, Chart.js, Plotly, and Excel, deriving scales, axes, and layout automatically from the data and 70+ semantic types like `Rank` or `Country` so agents skip manual configuration. Microsoft Research ships it as a JavaScript/TypeScript library plus a `flint-chart-mcp` server, letting LLM agents create, validate, and render charts inside chat environments from one human-editable input.

Solid Queue 1.6.0 now supports fiber workers (1 minute read)

Solid Queue 1.6.0 adds a fiber worker execution mode, letting Rails jobs run on a single Async reactor thread instead of a thread pool. You configure `fibers: 100` per worker instead of a thread count, which suits I/O-bound work like LLM calls at the cost of requiring the Async gem and fiber isolation (`config.active_support.isolation_level = :fiber`).

An API for MoQ: provision your own isolated relays (1 minute read)

Cloudflare released a MoQ provisioning API that lets developers create isolated Media over QUIC relays with separate credentials for publishers and subscribers, available across its 330-city network within seconds and with no servers to deploy or load balance. The service supports draft-14 and draft-16 of the MoQ Transport protocol with authentication, adding the isolation and access controls its earlier unauthenticated open preview lacked, and is free during beta.

Show HN: BitBang – Reach machines behind NAT from a browser, no account (1 minute read)

BitBang is a single static Go binary that gives you SSH-style remote access to machines behind NAT, CGNAT, or locked-down networks with no port forwarding, no daemon, and no account. Run `bitbang serve` on the target and it prints a URL that opens a terminal, file browser, and network proxy in any browser, with the connection end-to-end encrypted and peer-to-peer over WebRTC/DTLS while the signaling server only introduces the two ends.

Get Ready For the Powerful CSS border-shape Property! (1 minute read)

The CSS border-shape property applies clip-path-style values, including the new shape() function, to shape an entire element while letting border, box-shadow, and outline follow that shape rather than the element's rectangular box. Unlike clip-path or mask, which clip the whole element and drop decorations, border-shape preserves borders and shadows along the custom outline, though support is currently Chromium-only.

Ruby on Rails Patches Critical Vulnerability (1 minute read)

Ruby on Rails patched CVE-2026-66066, a critical (CVSS 9.5) arbitrary file read in Active Storage that lets unauthenticated attackers upload a crafted image to leak files, including the process environment, and escalate to remote code execution. The flaw hits apps using libvips for image processing with untrusted uploads; fixes ship in Active Storage 7.2.3.2, 8.0.5.1, and 8.1.3.1, and maintainers advise rotating any secret readable by the app process.

Rails patches critical Active Storage flaw with RCE potential (1 minute read)

The Rails team patched CVE-2026-66066, a critical Active Storage flaw that lets an unauthenticated attacker upload a crafted image to read arbitrary server files and potentially reach RCE when libvips handles thumbnail generation. Maintainers released fixes for the 7.2, 8.0, and 8.1 branches and urge rotating secret_key_base and other exposed credentials, having disclosed full details early after public PoC exploits appeared.
