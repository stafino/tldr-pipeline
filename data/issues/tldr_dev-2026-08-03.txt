Rust project goals: Immobile types and guaranteed destructors (1 minute read)

This Rust project goal proposes new auto-traits (Move, Destruct, Forget) that make relocatability and forgettability explicit per type, letting types opt out rather than assuming every value can be moved or dropped via mem::forget. The change would replace Pin's place-based immovability with type-level !Move for self-referential futures and enable guaranteed destructors for patterns like scoped async spawn, with viability tested against the Linux kernel.

AI migrated legacy COBOL programs to Java, bugs included (1 minute read) [flag]

This paper introduces the "Locksmith Loop," an agentic test-synthesis method that validates COBOL-to-Java migration by running both the source and generated target off-mainframe, searching input mocks to penetrate branches, then applying parity-preserving mutations to reach deeper paths. Across three case studies from 430 to 4,114 lines, it hit near-complete coverage on two open-source programs and 91.90% branch coverage on an internal one, with the Java matching the COBOL under deterministic parity checks.

Octane – React’s programming model, compiled (1 minute read)

Octane is a compiled React-alternative framework that ports React's hooks, Suspense, and actions to an ahead-of-time compiler with no virtual DOM, dropping dependency arrays and the rules of hooks by tracking what effects, memos, and callbacks actually capture. Components stay plain functions and existing .tsx keeps working, so teams can migrate one .tsrx component at a time while gaining parallel use() calls, streaming SSR, and direct keyed DOM updates.

Your agent needs a computer, not a container — introducing @cloudflare/computer (1 minute read)

Cloudflare released an early preview of @cloudflare/computer, an agent runtime that hands each agent its own computer and decides whether the code runs in an isolate, a container sandbox, or a browser. The package leans on Cloudflare's isolate primitive rather than per-agent containers, betting that isolates hibernate when idle and scale horizontally in ways containerized compute cannot as concurrent agents grow into the millions.

Workers RPC now works across Python and JavaScript (1 minute read)

Cloudflare extended Workers RPC to work across Python and JavaScript, letting a JavaScript Worker call methods defined in a Python Worker and vice versa with no schemas, protobuf, or dependencies. The system translates Structured Cloneable types across languages automatically, propagates exceptions to the call site, and requires only a Service binding, so cross-language calls behave like ordinary promise- or future-returning function calls.

Bonsai: Janestreet's UI Library (1 minute read)

Jane Street open-sourced Bonsai, an OCaml UI library for building reactive web apps where components are purely functional state machines and every value is incrementally recomputed only when its inputs change. Unlike React-style frameworks that fuse state, incrementality, and rendering into the component, Bonsai composes those primitives separately and, being OCaml, lets you share the same types across frontend and backend.

Cloudflare Workers and Containers now support inbound TCP connections and gRPC (1 minute read)

Cloudflare added inbound TCP support to Workers and Containers, introducing a `connect(socket)` handler that accepts sockets from its Spectrum ingress proxy and lets a Worker route them to another Worker, a Durable Object, or a container. The release enables full-duplex bi-directional gRPC from Containers and lets Workers serve unary and server-streaming gRPC APIs via gRPC-web, with Cloudflare converting requests automatically. Currently in private beta.

Hashimoto’s Superlogical bets that agentic software development needs more than a better terminal (2 minute read)

Mitchell Hashimoto's new startup Superlogical released a server-side multiplexer that stores authoritative session state on the server and streams raw terminal data to clients, which reconstruct the session locally via the libghostty rendering engine. Unlike tmux, which preserves one human's terminal across disconnects, it keeps long-running sessions alive across desktop, mobile, and web so developers and AI agents can share, resume, and monitor hours-long agent runs without losing execution context.
