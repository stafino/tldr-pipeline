ACEM: A Cost Estimation Model for Agentic Software Engineering (1 minute read)

This paper proposes ACEM, a cost estimation model for agentic software engineering that decomposes total cost into LLM tokens, human-in-the-loop oversight, and infrastructure, replacing the human-labor assumptions baked into COCOMO II and Function Points. Researchers found ChainDrop, a worm built on the Shai-Hulud codebase, has compromised more than 1,300 npm packages including Keyv, Cacheable, and flat-cache, which together see about 2B monthly downloads. The self-propagating malware harvests credentials from infected developer machines and republishes trojanized versions to npm, putting any project pulling in the affected dependencies at risk.

Keyv and friends compromised in active Shai-Hulud supply chain attack (1 minute read)

Attackers compromised the GitHub account of the keyv maintainer and used it to push a credential-stealing worm across the entire package family, including flat-cache and file-entry-cache, with poisoned releases published to npm carrying valid GitHub Actions provenance. The Shai-Hulud worm adds a preinstall hook that drops the Bun runtime to run an obfuscated secret stealer, and has now spread to at least 434 packages totaling over 2 billion monthly installs.

Massive ChainDrop npm supply-chain attack infects hundreds of packages (1 minute read)

Self-propagating malware named ChainDrop compromised at least 868 npm packages across 1,381 versions, including caching utilities like Keyv, Cacheable, and flat-cache that total 2 billion monthly downloads. The Shai-Hulud-based worm executes via a preinstall hook on npm install, deploys a Bun-run infostealer to exfiltrate developer and cloud credentials, and spreads to other maintainers' packages while carrying valid provenance from legitimate GitHub Actions workflows.

Keyv-Linked npm Worm Poisons Hundreds of Packages, Plants Claude Code and VS Code Hooks (1 minute read)

The Keyv repo also retained Claude Code and VS Code hooks that run the payload once a workspace is trusted, and responders should remove the malware's revocation watcher before rotating any exposed tokens.
