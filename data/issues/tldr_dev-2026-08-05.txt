Rust-lang/rust is adopting an LLM policy (1 minute read)

Five Rust project teams adopted an LLM policy governing how large language models can be used in contributions to the rust-lang/rust monorepo, covering PR authors, reviewers, and issue filers. The rules formalize existing moderation practices publicly, targeting three problems: polished output no longer signaling real understanding, easier code generation straining limited review bandwidth, and mechanical copy-pasting between contributors and models.

Beyond the usual preinstall hook, it plants persistence directly in VS Code and Cursor config that fires on IDE open, so a clean npm ci --ignore-scripts still leaves the credential-scraping payload live.
