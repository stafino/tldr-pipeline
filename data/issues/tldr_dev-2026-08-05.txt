EffiHolmes: Differential Profiling-Guided Repository Level Time Inefficiency Fix Localization (1 minute read)

EffiHolmes is an LLM framework that localizes the fix locations for time inefficiencies, the slow-but-correct code that produces no test failures or stack traces for traditional fault localizers to latch onto. It uses differential profiling across default and scaled workloads to separate real hotspots from noise, then LLM reasoning to map them to fix sites, improving file-level Acc@3 by 4.29 points with GPT-5.1 on the authors' new 140-issue RepoEffi-Bench.

Can LLMs Test Terminal User Interfaces? (1 minute read)

This paper builds a headless benchmark for testing terminal user interfaces across ratatui, bubbletea, textual, and ink, after finding that only 12% of test code in 197 real-world TUI apps exercises the interface and 45% of those never send input. Under equal wall-clock budgets no frontier LLM beats random exploration outright, though LLM guidance is more efficient per interaction and uniquely reaches input-gated faults, and line coverage turns out to poorly predict crash discovery.

‘Shai-Hulud: Here We Go Again’: Thousands of npm packages compromised in ‘Chaindrop’ malware campaign where hackers taunt victims (1 minute read)

A new Shai-Hulud variant dubbed "Chaindrop" compromised roughly 444 npm packages across 1,381 versions, starting from a hijacked GitHub account belonging to a keyv maintainer whose repositories total over two billion monthly downloads. The self-propagating worm harvests credentials, uses the stolen npm token to enumerate and republish every package the token can publish to, then RSA-encrypts the loot and exfiltrates it to a public GitHub repo.

Trojanized npm Packages Employ NullReceiver Tactic to Decode C2 IP from Blockchain (1 minute read)

Two trojanized npm packages, "bianira-ui" and "fluid-type-ui," used a technique dubbed NullReceiver to hide a command-and-control IP inside the recipient address of a zero-value Ethereum transfer, an evolution of EtherHiding that researchers have linked to North Korea. The packages drew a few hundred downloads before npm pulled them, and the dead-drop resolver approach leaves no smart contract or payload for defenders to track.

The Shai-Hulud npm worm didn't fake its security check — it earned a legitimate one (2 minute read)

An attacker hijacked the GitHub account of the keyv maintainer and pushed a credential-stealing worm to npm, which security firm Aikido tracked across at least 868 compromised packages carrying over two billion monthly installs. The poisoned releases shipped with valid npm provenance attestations rather than forged ones, because each build ran through the maintainer's own GitHub Actions workflow, showing that supply-chain trust signals hold only as long as the underlying account does.

Massive supply-chain attack compromises 440 packages under four hours (1 minute read)

A self-replicating worm compromised a GitHub maintainer account and injected credential-stealing code into more than 440 npm packages in under four hours on Tuesday, starting with keyv and its 600M monthly downloads before spreading to over 860 packages totaling 2B monthly installs. Built on TeamPCP's open-source Mini Shai-Hulud repo, the payload harvests npm, GitHub, AWS, and CI credentials plus AI config files and crypto wallets, with affected packages present in 46% of all cloud environments.
