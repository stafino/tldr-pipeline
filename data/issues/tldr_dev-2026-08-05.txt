EffiHolmes: Differential Profiling-Guided Repository Level Time Inefficiency Fix Localization (1 minute read)

EffiHolmes is an LLM framework that localizes the fix locations for time inefficiencies, the slow-but-correct code that produces no test failures or stack traces for traditional fault localizers to latch onto. It uses differential profiling across default and scaled workloads to separate real hotspots from noise, then LLM reasoning to map them to fix sites, improving file-level Acc@3 by 4.29 points with GPT-5.1 on the authors' new 140-issue RepoEffi-Bench.

Can LLMs Test Terminal User Interfaces? (1 minute read)

This paper builds a headless benchmark for testing terminal user interfaces across ratatui, bubbletea, textual, and ink, after finding that only 12% of test code in 197 real-world TUI apps exercises the interface and 45% of those never send input. Under equal wall-clock budgets no frontier LLM beats random exploration outright, though LLM guidance is more efficient per interaction and uniquely reaches input-gated faults, and line coverage turns out to poorly predict crash discovery.

The Warp Agent CLI (1 minute read)

Warp released the Warp Agent CLI, a standalone version of its multi-model coding agent that runs in any terminal, including Ghostty, iTerm 2, VS Code, and the built-in Windows and Mac terminals. Built on Warp's tmux-style multiplexing infrastructure, the agent manages pty connections directly, so it can switch directories mid-session, drive full-screen commands like sqlite and mysql, and run over SSH with no remote binary install.
