What We Observe as LLM Behavior Can Be a Side-effect of Inference Backend (1 minute read)

This paper runs a fully-crossed study of three instruction-tuned models across five inference frameworks, six benchmarks, and four generation modes, finding that the backend alone accounts for roughly 39% of the out-of-the-box variance a practitioner sees, even under greedy decoding. The authors recommend disclosing backend, version, and full generation config, and using deterministic decoding for any cross-backend comparison, since divergences hit factual benchmarks harder than social-bias ones.

A unified API for AI model routing (5 minute read)

Google Cloud API Gateway added model routing in Public Preview, a serverless ingress layer that accepts OpenAI-compatible requests and dynamically routes them to Gemini, Claude, or OpenAI OSS-GPT backends. Routing logic lives in an OpenAPI spec via an x-google-api-management extension, so teams can swap models without hardcoding endpoints or running their own proxy, and use it standalone for rate limiting and token tracking.

Java 28 starts to take shape (1 minute read)

JDK 28, a non-LTS release due March 2027, is taking shape around three JVM features: a preview of value objects, a switch of the Shenandoah collector's default to generational mode, and a preview of strict field initialization. Value objects are immutable and lack identity so the == operator compares by field value, while strict fields must be written before they are read, eliminating observable 0 or null defaults.

Google Workspace Directory Sync (1 minute read)

Clerk added Google Workspace support to Directory Sync, connecting directly to a Workspace directory via a service account with domain-wide delegation to sync users, groups, and group memberships without waiting for sign-in events. Google groups map to Clerk Roles and custom attribute mapping covers the full directory record, including standard fields like organizations.title and Workspace custom schemas such as customSchemas.EmployeeInfo.costCenter.
