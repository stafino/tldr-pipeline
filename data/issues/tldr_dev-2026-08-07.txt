The Bitter Lesson of Tool Calling (1 minute read)

This paper benchmarks programmatic tool calling (PTC), where tools are exposed as typed Python stubs the model invokes through code, against native JSON tool calling across 14 models on BFCL v4. PTC matches or beats JSON calls in 11 of 14 models, with the GPT-5.6 family gaining 10.6%, and it holds steady under context-rot conditions where JSON calling degrades an average of 2.3%.

Comparative Approaches to Agent Retrieval over Large Skill Libraries (1 minute read) [flag]

Testing two retrieval systems over a 690-skill library, this paper finds a hybrid lexical plus dense-embedding ranker hits the correct skill in its top five 73.5% of the time, while a typed knowledge graph of workflow relations scores 11.2 points worse at matched token budget. The authors attribute the failure to a pre-filter topology bound, since 98.6% of typed edges connect skills the ranker already surfaced together, so structure enriches relations but cannot extend retrieval reach.

Learning Context-Free Grammars for Grammar-Constrained Decoding via Declarative Agentic Programming with Guarantees (1 minute read)

Autogrammar is an agent that automatically learns context-free grammars for third-party DSLs from documentation and execution data, then uses them for grammar-constrained decoding to stop LMs from emitting syntactically invalid programs. Across CloudWatch Logs Insights, Dynatrace Query Language, and Datadog Search Syntax, the learned grammars hit near-perfect precision on unseen data and match or beat a professionally maintained grammar, with execution data proving essential and documentation dispensable.

Reasoning from Traces: Divergence-Guided Agentic Repair of WebAssembly Discrepancies (1 minute read)

WasmMend is the first system to automatically repair functional discrepancies between native and WebAssembly builds of the same C/C++ source, using differential trace analysis to pinpoint where the two executions first diverge before LLM agents reason about the root cause and patch it. Localizing the divergence first lifts the fix rate to 70%, versus 50.2% for a plain agentic baseline and 54.5% for one augmented with repair-time instrumentation.

Exploring Dependence, Overreliance, and Addiction Related Behaviors Associated with Large Language Model Use Among Software Engineers (1 minute read)

A survey of 119 software engineers found that LLM use has settled into functional dependence, with developers routinely reaching for models over documentation or peers while still verifying the output. Addiction-related patterns were rare and mostly showed up as trouble moderating use rather than impaired control, leading the authors to argue the real task is calibrating trust and preserving professional judgment, not curbing the habit.
