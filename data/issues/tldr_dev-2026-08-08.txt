Show HN: Wyzer Programming Language (1 minute read)

Wyzer is a statically typed, compiled language that combines choreographic programming, where the compiler projects a single distributed program into deadlock-free per-node binaries, with a Perceus reference-counting memory model that skips both a garbage collector and a borrow checker. It uses one ownership model for memory, threads, and network resources, makes network transfers explicit through assignment, and ships C ABI compatibility for systems interop.

PSA: Claude Code enabling auto mode as default next week, Anthropic says (1 minute read)

Anthropic will make Claude Code's auto mode the default permission setting on August 14 for Pro, Max, and Team users, replacing per-call approval prompts with a classifier that blocks irreversible or out-of-bounds tool calls and falls back to manual approval after repeated blocks.
