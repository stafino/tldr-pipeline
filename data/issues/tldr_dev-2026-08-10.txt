Tail-call optimization in C is relatively recent (1 minute read)

This LWN comment explains why C compilers lacked tail-call optimization for decades: the C calling convention makes the caller, not the callee, clean up stack arguments, so a call followed by a return could not collapse into a jump. GCC and Clang now handle these tail calls (including the interpreter-dispatch pattern), which lets Copy-and-Patch style interpreters scale to 100,000 code snippets rather than the sub-2,000 practical under goto-based dispatch.

What a Claude Code subagent actually costs: measuring the ~436k-token fixed overhead (3 minute read)

The author measured Claude Code subagent costs from session JSONL transcripts and found each spawned subagent carries roughly 436k tokens of fixed overhead, from initial context load plus the final-turn cache write, versus only about 46k tokens for the embedded content it actually reviews. The post shows how to reproduce the measurement and concludes that agent headcount, not payload size, is the real cost lever, making full-content embedding nearly free by comparison.

Meta is back with Muse Glimmer: local, agentic, multimodal, and open source (5 minute read)

Meta released Muse Glimmer, an open-source dense 30B multimodal model that pairs a 2B Perception Encoder for vision with a 28B text decoder, with day-0 support in transformers, llama.cpp, and vLLM. The decoder uses hybrid attention alternating three 2,048-token sliding-window layers with a full-attention NoPE layer, plus gated grouped-query attention that shares each KV head across 16 query heads to cut KV-cache memory 16x.

Meta returns to open source with Muse Glimmer, an Apache 2.0 licensed 30B parameter AI model optimized for agents — available now (3 minute read)

The weights are on Hugging Face now, with Ollama, LM Studio, vLLM, and llama.cpp support rolling out this week, and the permissive license drops Llama's 700M-monthly-user cap for unrestricted commercial use.

I got tired of heavyweight Markdown editors, so I built one in Rust + Tauri that doesn't ship a browser (3 minute read)

Bokuchi is an open-source Markdown editor built with Tauri v2, Rust, and React that renders through the OS-native WebView instead of bundling a Chromium instance like Electron apps do. The result is a small footprint and near-instant startup, with the trade-off being reliance on platform WebViews (WebView2, WKWebView, WebKitGTK) whose rendering behavior varies across Windows, macOS, and Linux.
