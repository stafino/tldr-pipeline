Dithered QR Codes (1 minute read)

This post explains how to embed a photo inside a QR code by shrinking each data module into the center of a three-by-three grid, freeing the surrounding cells to carry a low-res, one-bit image. It walks through the dithering techniques that make the embedded photo legible, from Bayer-matrix ordered dithering to Floyd-Steinberg error diffusion, while keeping the code scannable because scanners only sample each module's center.

Contract Testing in 10 Lines: JSON Schema Validation in Postman (2 minute read)

This tutorial replaces patchy field-by-field value assertions with JSON Schema validation in Postman, using the ajv validator built into the script sandbox to catch structural drift like renamed fields, vanished properties, or an integer id turning into a string. It shows how to define a schema in about ten lines, reuse it for array endpoints, and store it as a collection variable so every request validates against one shared contract.

Anthropic to put AI in charge of reviewing Claude Code actions by default (1 minute read)

Anthropic will make Claude Code's auto mode the default for new sessions on Pro, Max, and Team plans starting August 14, routing every tool call through a classifier that blocks irreversible or destructive actions before switching back to manual approvals after 20 blocks in a session. In a study of 1,053 paid testers, auto mode caught 89% of dangerous commands versus 13.6% for human review, and Anthropic will stop charging for the safety classifier's compute.

Message your other Claude Code sessions (1 minute read)

Claude Code v2.1.224 adds cross-session messaging, letting one session hand a finding, status, or decision to another through the new ListAgents and SendMessage tools without you copy-pasting between terminals. It works on macOS and Linux with no setup once sessions meet the version requirement, covers parallel worktrees and long-running jobs, and can reply to sessions on other machines though cross-machine exchanges must be started locally.

OpenChamber: An Agentic Development Environment (1 minute read)

OpenChamber is an agentic development environment that runs coding agents toward a set finish line across turns, with a Multi-run and Fusion mode that executes one task across up to five models and keeps or merges the best output. It works from GitHub issue to merged PR, runs prompts on a cron schedule, syncs across desktop, browser, phone, and VS Code, and keeps all code and session data local.

Anthropic is turning Claude Code’s auto mode on by default (1 minute read)

Anthropic is making Claude Code's auto mode the default for Pro, Max, and Team accounts starting August 14, so the agent will execute steps without per-action approval prompts unless it judges an action irreversible, destructive, or aimed outside your environment. In a 1,053-tester study, auto mode caught 89% of harmful actions versus 13.6% for manual review, and the rollout adds prompt injection screening and customizable hard deny rules.

Triton: DirectX 11 Driver for QEMU (1 minute read)

The UTM team released Triton, a Windows guest driver that pairs with their Neptune Direct3D forwarding layer to bring full DirectX 11 acceleration to QEMU virtual machines. Rather than swapping in Wine-style d3d11.dll and dxgi.dll replacements, Triton implements the DirectX device driver interfaces (DDIs), which avoids DWM's CPU blitting for a smooth desktop and sidesteps the anti-cheat detection that per-application DLL substitution triggers.
