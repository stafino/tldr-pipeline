Rust SIMD on the GPU (1 minute read)

VectorWare got Rust's portable SIMD (core::simd) running on the GPU, mapping a `Simd<T, N>` vector directly onto a warp's 32 lanes since NVIDIA's SIMT model is SIMD with per-lane addressing. Because portable SIMD lives in core rather than std, developers can write architecture-agnostic vector arithmetic, reductions, and lane shuffles once and have the compiler lower them to GPU hardware, adding parallelism below the thread level the company's earlier warp-mapped threads left unused.

Security Tests as Executable Specifications for LLM Code Generation: Benefits, Trade-offs, and Coverage Limits (1 minute read)

This paper tests security tests as executable specifications for LLM code generation, using a scaffold called SecTDD across 2,705 trajectories, 16 CWE categories, and two model families. Why you might want to build your WebApp in Canvas instead of HTML (5 minute read)

SpecPath: Testing Coding Agents Across Contract-Equivalent Specification Histories (1 minute read)

SpecPath is a diagnostic that tests whether coding agents produce the same behavior when a requirement is reached through different but contract-equivalent revision histories, holding the repository, final spec, verifier, agent, and budget fixed while varying only the path. Across five tasks and 14 agent configurations, aggregate accuracy barely moved, yet 35 of 100 blocks that passed on the direct spec failed on at least one equivalent history.

One Recipe, Many Harnesses: What Self-Evolution Encodes Across Languages and Models (1 minute read)

This paper studies self-evolving harnesses for coding agents, holding one evolution recipe fixed across eight programming languages and three base models to analyze what the evolved artifacts actually encode. The authors find that harnesses share an abstract playbook across languages but implement it with mostly disjoint ecosystem tooling, and that the shared core distills into one universal harness while a language-specific margin resists transfer and needs native re-evolution.

GitSkills: A Dataset of Agent Skills on GitHub (1 minute read)

GitSkills is a dataset of 3,797,117 SKILL.md files collected from 282,200 public GitHub repositories in July 2026, capturing how developers write, reuse, and maintain the agent-skill format Anthropic introduced in October 2025. The authors deduplicate to 1,877,981 distinct contents, enrich one representative per group with parsed front matter, folder contents, repo metadata, and partial commit history, and ship it as a single SQLite file for research on adoption, reuse, authorship, maintenance, and security.

Understanding the Architecture of Coding Agents: An Exploratory Study Using a Research Prototype (1 minute read)

This paper documents the internal architecture of coding agents and introduces Ark, a minimal open-source agent that preserves the essential components while stripping everything else for teaching and research. Running gpt-5.4-mini, Ark solved 8 of 10 tasks on the accompanying ArkBench suite with modest token consumption, and the authors compare its design against state-of-the-art agents using a recent architectural taxonomy.

TDD inside the agent loop - theater or actual value? (1 minute read)

Martin Fowler's team ran an exploratory eval on whether forcing a coding agent to follow TDD fully inside its own loop actually improves output, generating small, medium, and large greenfield tasks with Sonnet 4.6 and grading them with Opus. The result was no discernible quality gain, with non-TDD solutions occasionally ranked slightly higher on design and test quality and no meaningful difference in mutation scores.

Go is an ideal language for AI-assisted software engineering (1 minute read)

Google argues that as AI generates most code, a language's value shifts from how fast it lets you write to how easily humans can review, verify, and maintain what the agent produced. The post makes the case that Go's opinionated simplicity, uniform formatting and tooling, and long-term compatibility guarantees make agent-written code cheaper to read and safer to keep in production over years.

Agentic Code Quality (5 minute read)

Addy Osmani argues that code review no longer scales as the primary quality check once agents generate hundreds of thousands of changes a day, so quality now depends on the constraints you wrap around them. He frames quality gates such as unit and property tests, mutation testing, and complexity metrics as the deterministic loop that decides whether an agent's proposal is safe, correct, and scoped enough to ship.

Why Does CLAUDE.md Keep Growing? Catastrophic Remembering in Agentic Coding (1 minute read)

This paper argues that agentic coding instruction files like CLAUDE.md grow without bound because appending is cheap while safely deleting an instruction whose rationale is gone costs exponential verification, a failure mode the authors call catastrophic remembering. Across 247,694 instruction lifetimes in 1,867 repos, prompts more than tripled over their lifetime and old instructions grew steadily harder to remove, with the proposed fix being prompt comments that encode latent reasoning.

Can software factories actually work? (1 minute read)

PostHog examines whether "software factories" — pipelines where agents pull tickets, build PRs, and ship via CI/CD with minimal human review — can scale, weighing HumanLayer CEO Dex Horthy's viral argument that they never will against real-world adoption at Ramp, Cursor, Uber, and PostHog itself. The post frames autonomy as a spectrum, noting PostHog's agents write roughly 70% of its PRs while humans still skim at least 80% of them.

Relying on Go (5 minute read)

Solod is a systems language for C and Go developers that is literally a subset of Go, reusing its syntax highlighting, LSP, linters, package management, and much of its standard library code verbatim rather than trying to fix Go's mistakes. The trade-off is that Go's tooling doesn't know Solod is a subset, so it won't flag full-Go features that Solod doesn't support, and the language adds manual memory management with explicit allocators.

H3-metal – Native MiniMax-H3 inference for Apple Silicon (1 minute read)

h3.c is a native C implementation of MiniMax-H3 inference for Apple Silicon, running prompt-to-video and prompt-to-audio generation end to end through hand-written Metal blocks. It supports first/last-frame conditioning and ordered Ref2VA image references, plus an Iris-style interactive session that keeps BF16 prompt conditioning and the video decoder in memory so re-seeding a prompt skips reloading and re-encoding.

The best new features in Python 3.15 (3 minute read)

Python 3.15 reached its first release candidate with lazy imports that defer a module's cost until its code actually runs, plus new frozendict and sentinel() built-ins, better error messages, and faster JIT compilation. It also adds profiling.sampling, a statistical sampling profiler that trades cProfile's per-call precision for far lower runtime overhead, with the old deterministic profiler renamed to profiling.tracing.

Illinois just passed a law that puts Linux on the hook for age verification (1 minute read)

Illinois signed HB5511 (Public Act 104-0664) on July 31, which defines an "operating system provider" broadly enough to cover anyone shipping an internet-connected OS and requires them to build an age-declaration step and hand an age-bracket signal to any app that asks by January 1, 2028.
