n8n Sandbox Escape Lets Workflow Editors Run OS Commands as the n8n Process (1 minute read)

n8n patched a high-severity expression-sandbox escape (GHSA-gv7g-jm28-cr3m, CVSS 8.7) that let an authenticated workflow editor run OS commands as the n8n process on affected versions below 2.31.5 and 2.32.0–2.32.1. Security Joes showed the flaw could leak N8N_ENCRYPTION_KEY and decrypt stored credentials, opening paths to connected databases and cloud endpoints, so admins should update rather than rely on the interim access restrictions.

Go - Sending traces, logs and metrics to the Victoria* stack (2 minute read)

This tutorial walks through wiring a Go service to the VictoriaMetrics stack, sending each OpenTelemetry signal directly over OTLP/HTTP to its own component: metrics to VictoriaMetrics, logs to VictoriaLogs, and traces to VictoriaTraces, with no collector in between. The operational gotchas are the payoff: each signal listens on a different port and path (metrics drops the /insert prefix the other two require), and the Go SDK silently swallows 404s from a wrong path, so a typo ships zero telemetry with no error to tell you.
