Critical OpenWrt DHCPv6 Flaw Could Let Unauthenticated Attackers Run Code as Root (1 minute read)

OpenWrt shipped 24.10.8 to patch CVE-2026-53921, a CVSS 9.8 stack overflow in odhcpd that lets an unauthenticated attacker on the network run code as root via a crafted DHCPv6 REQUEST to UDP 547. Because odhcpd runs as root and embedded devices often lack stack canaries and ASLR, exploitation is realistic; 24.10 users should install 24.10.8 and 25.12 users 25.12.5, with public proof-of-concept code already circulating.

Tengu Botnet Reboots Compromised Linux Devices When Defenders Kill Its Process (1 minute read)

Nozomi Networks Labs documented Tengu, a Mirai-derived Linux botnet that abuses a device's hardware watchdog to reboot the host when defenders kill its main process, giving its other persistence mechanisms another shot at relaunching. The malware spreads via Telnet credential brute force, supports 25 DDoS methods plus a SOCKS5 proxy, and stands out for self-defense code that most Mirai variants lack.

Flaw From 2002 Exposes Data Centers to Server Takeover (1 minute read)

Researchers at Lava found that roughly 24,000 internet-exposed Baseboard Management Controllers are still vulnerable to CVE-2013-4786, an IPMI 2.0 flaw that leaks password hashes to unauthenticated clients and enables offline cracking for privileged server access. Because BMCs operate below the OS, kernel, and container layer, a compromise stays invisible to Datadog, Falco, and other host-level tooling, and Lava reports active exploitation in the wild.

Exposed BMCs hand out password hashes before login (1 minute read)

Lava researchers found 36,872 baseboard management controllers answering on the public internet via IPMI 2.0, and 24,650 of them handed out an HMAC-SHA1 password hash to unauthenticated requesters through CVE-2013-4786, a flaw dating to 2004. Because the BMC sits under the OS and offline cracking generates no failed logins, host security tools see nothing, and roughly a third of the captured hashes fell to public wordlists or Supermicro's 10-letter factory format.

24,650 Internet-Exposed BMCs Disclose IPMI Password Hashes Before Login (1 minute read)

Researchers found 24,650 of 36,872 internet-exposed BMC management interfaces leaking IPMI password hashes before authentication via CVE-2013-4786, a flaw baked into the IPMI v2.0 spec that Dell says has no patch. Over 30% of the recovered hashes cracked against common wordlists and factory chassis-sticker formats, exposing modern Supermicro and HPE GPU servers whose compromised BMCs give attackers OS-independent, reinstall-surviving persistence.

Disrupting supply chain attacks on npm and GitHub Actions (1 minute read)

GitHub shipped a set of npm and GitHub Actions changes to break common supply chain attack chains, including a 72-hour read-only lockout on high-impact npm accounts after an email change or 2FA-recovery-code use to blunt phishing-driven takeovers. The controls target specific links in the attack chain rather than one capability, aiming to slow credential exfiltration and the rapid malware spread that has hit hundreds of open source projects over the past year.

July 16 letter: the US EPA says power plants providing electricity only to data centers and not to the public grid wouldn't be subject to federal pollution laws (Tim McLaughlin/Reuters) (1 minute read)

How Do I Profile eBPF Code? (1 minute read)

This walkthrough shows how to measure the performance overhead an eBPF hook adds to a hot syscall path, using file open as the example. The method pairs a minimal C harness that calls SYS_openat directly, prefaults and mlocks its timing buffer, and discards a 10% warmup to isolate p50/p99 latency, then attaches perf with symbol resolution to pinpoint where the hook spends its time. The takeaway is a repeatable before-and-after profiling loop for any eBPF program running in production.
