Welcome CoHDI to the CNCF: Evolving Kubernetes into composable disaggregated infrastructures (1 minute read)

The CNCF accepted CoHDI (Composable Hardware in Disaggregated Infrastructure) as a Sandbox project, a Red Hat, Fujitsu, IBM Research, and NTT effort that hooks into Kubernetes Dynamic Resource Allocation to attach and detach PCIe devices on nodes at runtime. The target use case is LLM inference with prefill/decode disaggregation, matching the compute-bound prefill and memory-bound decode phases to separate hardware pools for better utilization and energy efficiency.

Three Critical VMware Flaws Allow Auth Bypass, Code Execution, and VM Escape (1 minute read)

Broadcom released patches for six VMware flaws across ESX, vCenter, Workstation, and Fusion, including two critical vCenter bugs (CVE-2026-59309 and CVE-2026-59310, both CVSS 9.8) that allow authentication bypass and remote code execution over the network. A third critical flaw (CVE-2026-47876, CVSS 9.3) lets an attacker with admin rights on a guest VM escape to execute code on the ESX host, so any team running vSphere should prioritize the fixed builds.

Hugging Face Rebuilt a Third of Its Infrastructure After Agent Intrusion (1 minute read)

Post-quantum authentication to origins is now supported (1 minute read)

Cloudflare added post-quantum authentication to its Authenticated Origin Pulls and Custom Origin Trust Store, letting teams run fully post-quantum mutually authenticated TLS to origin servers using ML-DSA signatures. This clears the first milestone on Cloudflare's roadmap to full post-quantum security by 2029, extending protection from harvest-now/decrypt-later encryption to the credentials attackers could forge once quantum machines can break classical signatures.

Tame Dependabot: Group your updates, slow the cadence, keep security fast (1 minute read)

GitHub engineers walked through how Microsoft's GCToolkit tamed Dependabot after finding that 92 of the repo's 578 commits were version bumps, 61 in the past year alone. Three config changes to dependabot.yml do the work: grouping updates per ecosystem, dropping the cadence from daily to monthly, and keeping security patches on a fast, separate track. The result is one predictable batch pull request per ecosystem instead of a daily drip of single-dependency noise that buries the updates that matter.
