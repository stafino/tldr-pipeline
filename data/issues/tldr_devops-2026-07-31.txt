Runtime Supply Chain Verification using the Node Resource Interface (NRI) (1 minute read)

This CNCF post argues that container supply chain verification via admission webhooks (Kyverno, OPA Gatekeeper, Sigstore Policy Controller) leaves gaps, since static pods, direct kubelet access, and webhook outages can silently skip signature checks. The Supply Chain NRI Plugin moves verification down to the container runtime, hooking CreateContainer events in both CRI-O and containerd so every container is checked regardless of how it was scheduled. The author frames it as defense-in-depth at a layer that cannot be bypassed, not a replacement for admission control.

How the controller-runtime Cache Actually Works, and Why Your Controller Does Not Crash the API Server (3 minute read)

This post explains that inside a controller-runtime reconciler, `r.Get()` and `r.List()` read from a local in-memory cache warmed by list and kept current via watch, not from kube-apiserver directly. The upside is near-free reads that hold up at hundreds of calls per second; the cost is multi-gigabyte memory footprints, hidden O(n) scans, and stale reads that surface under load. The Kubernetes blog has flagged some technical details as inaccurate and is preparing corrections.

Multi-Cluster databases on Kubernetes: Architecture and deployment (1 minute read)

This CNCF post walks through building a multi-cluster MongoDB deployment on Kubernetes that survives regional outages, control-plane corruption, and network partitions, using the open-source Percona Operator as the worked example. All nodes across clusters join a single replica set so cross-cluster voting can elect a new primary automatically, unlocking disaster recovery, live migrations, and zero-downtime maintenance. The post notes similar patterns exist for relational workloads through Vitess and CloudNativePG.

Session revocations at scale (5 minute read)

Each gateway keeps 12 hours of revocations in an in-memory cache and falls back to MySQL during token refreshes, but seeding that cache across hundreds of gateway pods turned every deploy into a coordinated read stampede on the database. The post walks through the caching redesign the team used to cut both database load and per-pod memory footprint.

The Economic Benefit of Refactoring (1 minute read)

Martin Fowler documents an experiment on an agent-written 150 kLoC application, where the data access layer ballooned to a single 17,155-line Rust file with no deduplication or extracted functions. The takeaway: refactoring an agentic codebase is an economic investment, spending tokens now to lower token consumption on all future work.

Reality-based Network Operations (5 minute read)

The core obstacle is multivendor inconsistency: NAPALM abstracts just five vendor operating systems, three of them from Cisco, and identical OS versions still expose different feature sets across devices. Making Postgres queues scale (1 minute read)

The DBOS team documented how they scaled Postgres-backed queues to 30K workflow executions per second across thousands of servers, challenging the usual advice to reach for RabbitMQ or Redis at scale. The core fix is `FOR UPDATE SKIP LOCKED`, which lets thousands of polling workers dequeue concurrently without fighting over the same rows, lifting throughput past the ~100/second ceiling that naive dequeue queries hit under contention.
