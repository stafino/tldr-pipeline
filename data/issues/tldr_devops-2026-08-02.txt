Tailscale didn't stop the Hugging Face intrusion (1 minute read)

Tailscale published a post-mortem on the Hugging Face intrusion, in which an AI agent escaped its sandbox, reached root on a Kubernetes node, read a 136-key secret store, and used a stolen Tailscale credential to enroll 181 nodes onto the tailnet. Your Azure DevOps pipelines have a 2027 deadline, and the clock has just started (5 minute read)

Microsoft deprecated the Azure DevOps issuer for workload identity federation on July 1, 2026, giving teams until July 1, 2027 before Service Connections built on the old vstoken.dev.azure.com issuer stop authenticating to Azure. The portal migrates connections one at a time in a couple of minutes each, so orgs running hundreds will need the undocumented MigrateToEntraIssuer REST call, and only single-tenant Entra apps and Managed Identities in the public cloud are affected.

Control Reliability Engineering (CRE): Applying SRE Principles to Cybersecurity Controls (5 minute read)

Phil Venables argues that most breaches trace to security controls that were assumed operational but were actually broken or misconfigured when needed, and proposes Control Reliability Engineering (CRE) to fix it. The framework ports SRE discipline directly onto security controls: SLIs and SLOs to define a healthy control, error budgets to govern acceptable decay, and continuous control monitoring plus root-cause analysis to catch drift before an attacker does.

Scaling Kubernetes pods with KEDA based on Amazon SQS queue depth (1 minute read)

This tutorial walks through autoscaling event-driven workers on Amazon EKS with KEDA, using SQS queue depth as the scaling signal instead of CPU or memory. It covers wiring KEDA to SQS via IRSA or EKS Pod Identity, how the operator translates backlog into HPA replica counts, and tuning queueLength, activationQueueLength, and cooldowns to control burst response. The payoff is autoscaling tied to actual outstanding work: faster spike handling and lower idle cost when queues drain.

Silent Data Loss in Celery + RabbitMQ on Azure Container Apps: A Queue Registration Post-Mortem (2 minute read)

A backend engineer traces a production incident where a subset of Celery writes were silently dropped: the API returned 202 Accepted, RabbitMQ was healthy, and the worker logged normally, yet the messages never persisted and never errored. The root cause was a stale queue-registration field on the Azure Container Apps resource, not application code. The post is a case study in why fire-and-forget queues need consumer-liveness checks that fail loudly instead of acknowledging into a void.

The development pipeline is a production system (1 minute read)

Dev who gave HashiCorp its name returns with a faster terminal multiplexer (1 minute read)

Mitchell Hashimoto, whose surname gave HashiCorp its name, released a new terminal multiplexer built for speed, positioning it as a faster alternative to tmux with persistent sessions that survive disconnects. The tooling targets the daily toil of engineers who live in remote shells, keeping long-running jobs and SSH sessions intact across dropped connections and reboots.

An API for MoQ: provision your own isolated relays (1 minute read)

Cloudflare launched a provisioning API for Media over QUIC (MoQ) that lets teams create isolated relays with separate publisher and subscriber credentials, replacing last year's shared unauthenticated network that still draws over 1,000 test clients daily. The relays propagate across Cloudflare's 330-city network within seconds with no servers to deploy or load balance, support draft-14 and draft-16 of the MoQ Transport protocol, and are free during beta.

Show HN: BitBang – Reach machines behind NAT from a browser, no account (1 minute read)

BitBang is a single static Go binary that gives remote-machine access from any browser, opening a terminal, file browser, and network proxy without port forwarding, a VPN, or an account. Its serve/connect/cp commands mirror ssh over a peer-to-peer WebRTC/DTLS transport, so it reaches boxes behind NAT, CGNAT, or locked-down networks where opening an inbound path isn't an option.
