The release also splits experimental resources into a separate gateway.networking.x-k8s.io API group, and deprecates the v1alpha2 route versions ahead of removal in a future release.

Your Azure DevOps pipelines have a 2027 deadline, and the clock has just started (5 minute read)

Microsoft deprecated the Azure DevOps issuer for workload identity federation on July 1, 2026, giving teams until July 1, 2027 before Service Connections built on the old vstoken.dev.azure.com issuer stop authenticating to Azure. The portal migrates connections one at a time in a couple of minutes each, so orgs running hundreds will need the undocumented MigrateToEntraIssuer REST call, and only single-tenant Entra apps and Managed Identities in the public cloud are affected.

How to Run Isolated Tenant Kubernetes Clusters on Shared GPU Infrastructure (1 minute read)

NVIDIA's developer blog documents a pattern for giving each team its own isolated Kubernetes control plane without splitting the underlying GPU hardware. The setup pairs vCluster, which provisions per-team API servers, CRDs, and RBAC indistinguishable from a dedicated cluster, with KAI Scheduler, which carves a shared GPU pool into per-team quotas. The tutorial runs three tenant clusters on a single NVIDIA L40S, and the authors note the same queue hierarchy and node pool scale to hundreds of GPU nodes and dozens of teams.

Control Reliability Engineering (CRE): Applying SRE Principles to Cybersecurity Controls (5 minute read)

Phil Venables argues that most breaches trace to security controls that were assumed operational but were actually broken or misconfigured when needed, and proposes Control Reliability Engineering (CRE) to fix it. The framework ports SRE discipline directly onto security controls: SLIs and SLOs to define a healthy control, error budgets to govern acceptable decay, and continuous control monitoring plus root-cause analysis to catch drift before an attacker does.

GEM Training: How Meta Doubled the Efficiency of Its LLM-Scale Ads Foundation Model (1 minute read)

Meta detailed how it scaled GEM, the foundation model behind Instagram and Facebook ads recommendations, to LLM-scale training on several thousand latest-gen GPUs. The team doubled end-to-end efficiency to 20-25% Model FLOPs Utilization while growing training FLOPs 4x in 12 months, using custom recommendation kernels, MXFP8 precision, and topology-aware 5D parallelism. The writeup is a reminder that LLM training recipes do not transfer cleanly to trillion-parameter recommendation models.

Show HN: NixOS-DGX-Spark – Nix and NixOS on the DGX Spark (1 minute read)

A developer released NixOS-DGX-Spark, an open-source project that brings Nix and NixOS to NVIDIA's DGX Spark and the Asus Ascent GX10, shipping USB images and a NixOS hardware module with a custom NVIDIA-optimized kernel for full GPU and Ethernet support. Teams can run the Nix dev shells and playbooks directly on stock DGX OS via nix-gl-host, or install NixOS outright for reproducible CUDA environments after a required firmware update.

Cortex Framework v7 is GA: Build agentic workflows without disrupting SAP operations (2 minute read)

Google Cloud made Cortex Framework v7 generally available, adding purpose-built data product accelerators that turn raw SAP ERP tables into semantically rich, agent-ready data products deployed directly in BigQuery and Knowledge Catalog. Orchestration now runs on Dataform for version-controlled, modular workflows, letting data teams feed Gemini Enterprise agents accurate business context without slowing mission-critical SAP operations or standing up separate pipeline infrastructure.
