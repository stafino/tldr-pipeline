Keyv and friends compromised in active Shai-Hulud supply chain attack (1 minute read)

Attackers compromised the maintainer's GitHub account behind keyv and its sibling caching libraries, then pushed a malicious preinstall dropper and cut fresh npm releases signed by GitHub Actions, spreading the Shai-Hulud worm across at least 434 packages with over 2 billion monthly installs. The payload harvests environment secrets and exfiltrates them to public GitHub repos, so any recent npm install pulling flat-cache, file-entry-cache, or cacheable is a potential credential leak.

Decades-Old BMC Vulnerability Exposes Thousands of Data Centers to Attacks (1 minute read)

Data center security firm Lava reported that CVE-2013-4786, a 22-year-old flaw in the IPMI 2.0 authentication protocol, exposes roughly 37,000 internet-facing BMCs by leaking password-derived hashes for offline cracking. Because IPMI, Redfish, and the web console often share one credential database, a cracked hash unlocks the data center's most privileged control plane, and Lava found thousands of hosts already accepting empty usernames or default passwords.

Source-Bounded Exact Recovery over Docker's Logs API (1 minute read)

This paper defines source-bounded exactness for Docker log collection and shows that a persisted read position alone does not guarantee recovery after container lifecycle changes. Across 120 collector runs, a fixed LogDeck was exact in 60/60 while Grafana Alloy 1.18.0 managed 20/60, missing retained history whenever recovery required rediscovering an exited or restarted source. The takeaway for platform teams is that lifecycle reacquisition, not a saved offset, determines whether logs survive restarts.

Doc2CI: A Multi-Service Study of CI Configuration Generation Using Large Language Models (1 minute read)

This paper introduces Doc2CI, a benchmark of 3,363 description-to-YAML pairs from four CI services, and evaluates 16 models across 53,000 generated configurations. Exact reference reproduction never tops 3.1%, and while 97% of outputs parse as YAML, only 71% satisfy service schemas, with larger models improving validity and code specialization offering no consistent edge. A training-free, schema-guided repair pass lifts schema validity to 94%, suggesting teams should treat structural validity as a distinct target from documentation similarity.
