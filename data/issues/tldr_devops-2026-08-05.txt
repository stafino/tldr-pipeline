New OVSwrap Linux Kernel Flaw Lets Local Users Gain Root via Open vSwitch (1 minute read)

A memory-corruption flaw in the Linux kernel's Open vSwitch datapath, tracked as CVE-2026-64531 (CVSS 7.8) and codenamed OVSwrap, lets an unprivileged local user reach root on default-configured distros via unprivileged user namespaces, and a public exploit ships with records for roughly 800 kernel builds. Fixes landed upstream on July 24, but check your vendor tracker rather than upstream numbers, and unload the openvswitch module where OVS is not required.

Critical Gitea Flaw Let Unauthenticated Attackers Read Server Files via Org-Mode Markup (1 minute read)

Gitea patched CVE-2026-59774, a critical file-read flaw (CVSS 9.8) that let unauthenticated attackers read any file the service account can access on self-hosted instances running 1.22.1 through 1.27.0, using only crafted Org-mode markup against a public repository. Self-hosted admins should upgrade to 1.27.1 immediately, and if logs show the markup endpoint was hit, rotate the internal token, OAuth and JWT material, and database credentials.

CISA Warns of Exploited Langflow, N-central, and Tomcat Vulnerabilities (1 minute read)

CISA added three actively exploited flaws to its KEV catalog, including a 9.8-severity Langflow OSS bug (CVE-2026-9198) that chains an auth-bypass token endpoint with a code-validation endpoint for unauthenticated RCE. Also flagged are an N-able N-central authentication bypass exploited as a zero-day for admin access, and an Apache Tomcat EncryptInterceptor bug whose patch flipped encryption from fail-closed to fail-open.

Leaked n8n API Tokens Exposed Live Instances to Credential Theft (1 minute read)

GitGuardian researchers scanned public GitHub commits and found 4,576 exposed n8n API tokens, with 321 live instances accepting at least one leaked credential, roughly 36% of the reachable instances they tested. Because n8n workflows store credentials for databases, cloud environments, and internal systems, a single leaked token grants authenticated access to downstream secrets using only documented REST API calls, no CVE required.

The Agent Access Model (1 minute read)

Cloudflare proposes the Agent Access Model, an access-control framework arguing that BeyondCorp-style Zero Trust breaks quietly when the principal is an AI agent rather than a human at a device. The authors note that human-shaped controls fail by granting too much, seeing too little, and trusting too long, so AAM shrinks each agent's capability ceiling instead of trying to make every access decision smarter. The post separates single-principal controls available today from the harder multiplayer access-control problem.

WriteGuard: fine-grained controls for MCP Servers (1 minute read)

The controls target the blast radius of misconfigured agents, closing entire ticket queues or dropping database tables, where network logs cannot distinguish one agent session from a human operator.

Catching rogue AI behavior with identity-aware analytics (1 minute read)

Cloudflare launched Identity-aware AI Gateway in open beta, pairing Cloudflare Access with every request so each call carries a verified SAML identity (via Okta, Entra, or any provider) as `cf.user_id` instead of shared API keys. User Insights, now generally available to all AI Gateway customers at no cost, builds a behavioral baseline per user and agent to flag spend spikes and rogue agents routed through tools like Claude Code, Codex, and Copilot.
