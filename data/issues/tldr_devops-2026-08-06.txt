AWS, Google, and Vercel Agent Flaws Let Attackers Trigger Tools Without Running the Model (1 minute read)

AWS, Google, and Vercel patched flaws in their agent frameworks that let forged tool-call payloads reach an agent's dispatch path without a legitimate model turn, bypassing system prompts, content filters, and model-level guardrails entirely. The fixes landed in Bedrock AgentCore, Google ADK 2.5.0, and Vercel's @ai-sdk/harness-codex 1.0.29 and harness-opencode 1.0.28, with blast radius bounded by whatever sensitive tools each agent was already wired to.

Hackers Start Exploiting Recent JetBrains TeamCity Vulnerability (1 minute read)

CISA warned that threat actors are exploiting CVE-2026-63077, a critical (CVSS 9.8) deserialization flaw in JetBrains TeamCity On-Premises that lets unauthenticated attackers reach RCE via the agent polling protocol and run OS commands as the server process. JetBrains shipped fixes in versions 2025.11.7 and 2026.1.3 plus a patch plugin for 2017.1+, and CISA's KEV listing gives federal agencies three days to patch.
