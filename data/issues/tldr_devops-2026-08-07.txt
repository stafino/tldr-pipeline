ChainDrop supply chain compromise: Anatomy of a self-propagating worm (5 minute read)

Microsoft Threat Intelligence documented ChainDrop, an npm supply chain attack that pushed a self-propagating Shai-Hulud worm variant into more than 400 packages across unrelated publishers, including keyv, flat-cache, and cache-manager. The malware runs from a preinstall hook to harvest npm, GitHub, AWS, Kubernetes, and Vault credentials, then republishes packages under stolen publishing tokens, so any build runner that installed an affected release should be treated as compromised and its credentials rotated.

18-Year-Old Linux SCTP Flaw Could Let Local Users Gain Root and Escape Containers (1 minute read)

An 18-year-old use-after-free bug in Linux's SCTP networking code, tracked as CVE-2026-64564 and dubbed SCTPhantom, lets a local user with SCTP reachable gain root, and Tencent's Zhuque Lab says it used the flaw to escape a container to the host. Stable kernels 7.1.6, 6.18.42, 6.12.101, and 6.6.148 shipped the fix on August 3, so anyone running an older kernel with SCTP exposed should patch.

Does Kubernetes DRA Replace HAMi? (1 minute read)

DRA's consumable capacity feature, generally available in Kubernetes v1.34 and on by default since v1.35, lets a pod ask the scheduler directly for a slice of a GPU's memory, absorbing the encoding job HAMi built its mutating webhook and scheduler extender to do. The author argues DRA still doesn't replace HAMi, because in-container enforcement at CUDA-call granularity is a job DRA was never designed for. HAMi's response is to split the two: keep enforcement, and rebuild the encoding on top of DRA across three repositories.

eMicro: Real-Time Multi-Hop Access Control for Microservices with eBPF (1 minute read)

This paper introduces eMicro, a path-aware access control system that stops multi-hop attacks in microservice meshes, where each individual service-to-service call looks legitimate but the full request path violates security intent. It encodes policies as deterministic finite automata for constant-time lookups and uses eBPF-based in-kernel request tracing to enforce them without code changes. On DeathStarBench and production traces from Uber, Alibaba, and ByteDance, the authors report 1-microsecond policy checks, 50M policies in 100MB, and 90% lower propagation overhead.
