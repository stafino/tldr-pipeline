We replaced Redis with MySQL for inventory reservations and it scaled (1 minute read)

Shopify's engineering team rebuilt its checkout oversell-protection system on MySQL 8 after years on Redis, moving to one row per inventory unit and using SKIP LOCKED to handle concurrent reservation contention. The design held Shopify's high-throughput targets through Black Friday 2025, when merchants peaked at $5.1M in sales per minute. The post's sharpest lesson is operational: the real bottleneck wasn't in the metrics the team was already watching.

Why observability doesn’t explain what happened (3 minute read)

The author argues that observability tells you what is happening inside a system but rarely why, leaving teams to burn two to three hours per incident correlating telemetry against deploys, change records, and support tickets that live outside the stack. The fix isn't better dashboards but connecting infrastructure signals to the context that explains them, since support often knows customers are affected before the first alert fires.

Docker Sandboxes – Disposable, isolated sandboxes for AI agents (1 minute read)

Docker released Docker Sandboxes, a CLI tool that runs coding agents like Claude Code, Codex, and Gemini CLI inside disposable microVMs with configurable network and filesystem controls, isolating the host from anything an agent does. The microVM boundary makes "YOLO mode" (`--dangerously-skip-permissions`) safe to run unattended, and paid Docker AI Governance layers on org-wide network, filesystem, and MCP policies enforced across every developer's machine.

Chainloop: Open-source evidence store and policy engine for the software supply chain (1 minute read)

Chainloop, an open-source evidence store and policy engine for the software supply chain, runs a CLI inside GitHub Actions, GitLab, Jenkins, or Dagger pipelines that collects build artifacts, stores them in content-addressable storage, and references each in a signed in-toto attestation. Workflow Contracts declare which materials a build must emit and attach Rego policies via Open Policy Agent, so the pass-or-fail verdict travels inside the signed record rather than a dashboard someone can edit later.
