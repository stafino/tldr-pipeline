The collaboration integrates Docker's Model Runner with ModelPack's open format, letting platform teams push, store, and pull models through the same OCI registries they already run for container images.

CNCF Announces Graduation of Cloud Native Buildpacks, Advancing the Standard for Container Builds (1 minute read)

The Cloud Native Computing Foundation graduated Cloud Native Buildpacks, its toolkit for building OCI-compliant container images directly from source code by automating language detection, dependency installation, and image layering. The roadmap targets expanded OCI Artifacts support, stronger SBOM workflows, and WebAssembly compatibility, with Bloomberg and Heroku by Salesforce among the active code contributors.

Hackers Breach Polish Power Plant Controls via Private Cellular Network and Shut Turbine (1 minute read)

CERT Polska disclosed that attackers shut down a steam turbine and process-water treatment at a Polish combined heat and power plant by pivoting from a compromised wind farm through a shared private cellular APN, the first real-world use of that vector. The APN allowed client-to-client traffic and the reachable WAGO controller still had default credentials, so CERT's fix is APN client isolation and treating cellular links as untrusted from the OT side.

A Malicious SIM Card Can Run Attacker Code Inside the Modems Behind Cellular IoT Devices (1 minute read)

Researchers at the University of Birmingham and Fuzzware showed that a malicious SIM can issue a proactive RUN AT command to execute attacker code on the cellular modem, and they used it to take over a commercial EV charger. The flaw hit 9 of 26 tested devices, mostly Quectel machine-to-machine modules in EV chargers, industrial routers, and telematics units, so operators should ask suppliers whether RUN AT is enabled and can be disabled.

PQC in Plaintext: Google Cloud’s post-quantum cryptography roadmap (2 minute read)

Google Cloud published its post-quantum cryptography roadmap, committing to full PQC readiness across internal infrastructure and customer-facing services by 2029, ahead of the CNSA 2.0 and NIST IR 8547 deprecation windows of 2030-2035. The strategy prioritizes Store Now, Decrypt Later mitigation, signature integrity, and cryptographic agility, with rollouts extending to Sovereign Cloud offerings like Google Distributed Cloud and to AI workloads.

Why observability doesn’t explain what happened (3 minute read)

The author argues that observability tells you what is happening inside a system but rarely why, leaving teams to burn two to three hours per incident correlating telemetry against deploys, change records, and support tickets that live outside the stack. The fix isn't better dashboards but connecting infrastructure signals to the context that explains them, since support often knows customers are affected before the first alert fires.

How to Pretty-Print Your Kubernetes YAML as KYAML and Why You'd Want To (3 minute read)

Kubernetes SIG CLI introduced KYAML, a strict subset of standard YAML for writing manifests that parses with existing tooling and no new parser. It fixes the format's known traps by dropping whitespace-sensitive structure, always quoting strings to kill silent type coercion like the Norway Bug, and using explicit braces and brackets. The payoff is safer Helm templating and manifests that mean the same thing to every reader.

Brex watches AI agents at the network layer (5 minute read)

Brex deployed the open-source OpenClaw agent against internal roles, then moved its security perimeter from the code to the network layer after its security team refused to trust an agent with unrestricted code execution. Rather than restricting tool usage the way Nvidia's NemoClaw does, Brex built CrabTrap to monitor what the agent's container actually sends and receives, preserving the coding capabilities while policing egress. CEO Pedro Franceschi argues the coding ability is the point, so the boundary belongs where the code talks to the outside world.

GitHub already has an EDR. You just have to listen to it (2 minute read)

At Black Hat USA 2026, Microsoft's Yossi Weizman and Echo's Mor Weinberger argued that GitHub's own event stream is enough to detect supply-chain attacks that endpoint and network telemetry miss. Studying incidents like Shai-Hulud, Trivy, and Megalodon, they found recurring techniques such as forged commit identities, poisoned tags, workflow abuse, and OIDC theft, with the authenticated pusher rarely matching the forged commit author. Their open-source GitHub Threat Detector ships 22 production and 12 beta rules, correlating weak signals into high-confidence alerts.
