Hackers Breach Polish Power Plant Controls via Private Cellular Network and Shut Turbine (1 minute read)

A Malicious SIM Card Can Run Attacker Code Inside the Modems Behind Cellular IoT Devices (1 minute read)

The flaw hit 9 of 26 tested devices, mostly Quectel machine-to-machine modules in EV chargers, industrial routers, and telematics units, so operators should ask suppliers whether RUN AT is enabled and can be disabled.

A practical guide to solving when zero+zero=two in mesh observability (1 minute read)

Metrics and logs survive the mismatch, but traces are the piece that silently falls apart until you wire the Collector correctly.

Deeply buried 16-year-old SQLite bug caused last year's Tailscale outages (1 minute read)

A postmortem traces Tailscale's intermittent outages last year to a 16-year-old bug in SQLite's query planner, which under specific conditions returned incorrect results rather than erroring out. The root cause sat far beneath the application layer, in a dependency most teams treat as bulletproof, and evaded detection until the failure pattern was correlated across incidents. The takeaway for platform teams is that even battle-tested foundational libraries belong in the blast-radius analysis when debugging inexplicable data-layer behavior.

Lightweight Dragonfly Deployment: P2P Distribution Without the Database Stack (1 minute read)

Dragonfly's peer-to-peer image distribution normally ships with a full control plane: a Manager backed by MySQL and Redis for dynamic config, multi-cluster coordination, and registry preheating. This post documents a lightweight deployment that drops all three, leaving the Scheduler as the sole coordinator and swapping the database stack for a ConfigMap and a headless Service. For a single cluster fighting registry overload on image pulls, it installs with one Helm command and cuts the operational surface to what a solo cluster actually needs.

How to Pretty-Print Your Kubernetes YAML as KYAML and Why You'd Want To (3 minute read)

Kubernetes SIG CLI introduced KYAML, a strict subset of standard YAML for writing manifests that parses with existing tooling and no new parser. It fixes the format's known traps by dropping whitespace-sensitive structure, always quoting strings to kill silent type coercion like the Norway Bug, and using explicit braces and brackets. The payoff is safer Helm templating and manifests that mean the same thing to every reader.

Brex watches AI agents at the network layer (5 minute read)

Canva redesigns session revocation for 100M active sessions (5 minute read)

Canva rebuilt its session revocation system to handle hundreds of millions of active sessions without a networked database lookup on most auth requests. Instead of hitting MySQL, gateways read 16-byte binary revocation records from immutable 30-minute S3 objects, using conditional GETs to pull only changed chunks and sorted in-memory arrays that cut the revocation cache footprint by 87.5%. The writeup treats S3 as a coordination primitive, with conditional PUTs for optimistic concurrency and ZooKeeper leader election as an optional conflict-reducer rather than a correctness requirement.

The author's core claim is that platform engineering should own the AI pipeline as another self-service golden path, or teams will recreate shadow IT with prompts instead of Jenkinsfiles. The practical guidance covers treating prompts as versioned artifacts and monitoring for model drift, cost creep, and degrading integrations after deployment.
