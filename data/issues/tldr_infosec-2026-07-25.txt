Fastjson 1.x RCE Vulnerability Targeted in Attacks With No Patched Available (1 minute read)

Attackers are exploiting CVE-2026-16723 (CVSS 9.0), an unauthenticated RCE in Alibaba's Fastjson 1.x library that lets a malicious JSON request run code in affected Spring Boot fat-JAR applications with SafeMode left at its disabled default. Alibaba has not shipped a fixed 1.x release as of July 25, so defenders should enable SafeMode via -Dfastjson.parser.safeMode=true or pin fastjson:1.2.83_noneautotype while migrating to Fastjson2.
