Anthropic’s Claude Cowork could escape its local VM and read credentials on a Mac (1 minute read)

Accomplish AI researchers demonstrated SharedRoot, an attack that let Anthropic's Claude Cowork escape its local Linux VM sandbox and read SSH keys and cloud credentials across the host Mac. The chain exploited CVE-2026-46331, a "pedit COW" kernel privilege-escalation flaw, to gain guest root, then reached the host through a writable VirtioFS mount. Anthropic closed the July 23 report as informative; local execution remains exposed.

GitHub, PyPI add time-absed defenses against supply chain attacks (1 minute read)

GitHub and PyPI added time-based defenses to blunt package supply-chain attacks. Dependabot now applies a default three-day cooldown before opening update PRs for newly published packages, giving detection tools time to flag malicious releases before they reach CI, while PyPI rejects new files added to any release older than 14 days to stop attackers with stolen tokens from poisoning trusted versions. GitHub still recommends lockfile pinning, restricted-scope tokens, and disabling unnecessary install scripts for longer-term compromise.
