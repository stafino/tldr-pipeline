PTC Windchill Vulnerability Exploited in Ransomware Campaign (1 minute read)

A Cl0p ransomware affiliate is exploiting CVE-2026-12569 (CVSS 9.3), an unauthenticated deserialization RCE in PTC's Windchill and FlexPLM platforms, chaining a FlexPLM WSDL information disclosure with a Windchill login servlet flaw to drop JSP webshells. PTC patched the bug on June 17 and CISA added it to the KEV catalog in late June; apply patches, hunt with the ReliaQuest and Ransom-ISAC IoCs, and treat aerospace, automotive, manufacturing, and retail exposure as targeted.

PoC exploit released for critical AD CS domain-takeover flaw (CVE-2026-54121) (1 minute read)

Researchers released a PoC exploit and technical writeup for CVE-2026-54121 ("Certighost"), a critical improper-authorization flaw in Active Directory Certificate Services (CVSS 8.8) that lets an authenticated attacker coerce the CA into issuing a certificate authenticating as a targeted machine account, including a Domain Controller. Microsoft patched the flaw on July 14 and rated it "less likely" to be exploited, an assessment that may change now that working exploit code is public.

New ransomware targets AI model weights and can't even collect the ransom (3 minute read)

ENCFORGE, a Go ransomware documented by Sysdig on July 20, exploits CVE-2025-3248, a missing-authentication flaw in Langflow's code-validation endpoint that grants unauthenticated Python execution, to encrypt AI model weights across roughly 180 extensions including PyTorch checkpoints, SafeTensors, and GGUF files. The JADEPUFFER-linked binary has no exfiltration or payment channel, so its only leverage is destruction, and standard database backups won't cover fine-tuned models Sysdig estimates cost $75,000 to $500,000 to rebuild.

Claude Cowork escaped sandbox on Mac, gain full access to all files (1 minute read)

Researchers at Accomplish AI disclosed SharedRoot, a sandbox-escape flaw in Anthropic's Claude Cowork that let a single crafted message break out of the agent's Linux VM to read and write files anywhere on a Mac, and harvest login credentials, with no permission prompt shown. Roughly 500,000 local Cowork users were affected; the patched build defaults to cloud execution, but users who still run the agent locally remain exposed unless they disable unprivileged user namespaces and restrict filesystem sharing.

New GitHub, PyPI Policies Boost Supply Chain Security (1 minute read)

GitHub and PyPI rolled out new supply-chain defaults that narrow the window for malicious package versions. GitHub's Dependabot now waits three days before opening pull requests for non-security version bumps, giving scanners and maintainers time to catch and pull poisoned releases; the cooldown is configurable in dependabot.yml. PyPI will block new file uploads to releases older than 14 days, preventing attackers with stolen publishing tokens from poisoning long-stable versions.

Microsoft introduces MAI-Cyber-1-Flash, an AI model trained for cybersecurity, and launches Perception, an agentic security system to patch vulnerabilities (New York Times) (1 minute read)

Microsoft introduced MAI-Cyber-1-Flash, a model trained specifically for cybersecurity tasks, alongside Perception, an agentic system that autonomously detects and patches vulnerabilities. The release puts Microsoft in direct competition with security-focused AI offerings and signals a push toward automated remediation, though defenders should validate agent-generated patches before trusting them in production.

Exclusive: Cogent Security debuts VR-1, a frontier model built to prove attack paths (1 minute read)

Cogent Security introduced VR-1, a frontier reasoning model trained to find and prove exploitable attack paths inside live enterprise environments rather than flag isolated bugs. On its own IntrusionBench, VR-1 proved twice as many paths as Claude Opus 4.8, Kimi K3, and GLM-5.2 at roughly a quarter of the cost, though all three closed to within a few points when run inside Cogent's harness.

We’re open sourcing our privacy proxy CLI (1 minute read)

Cloudflare open-sourced pvcli, a command-line tool under Apache-2.0 for exercising privacy-preserving protocols, starting with Oblivious HTTP requests across a relay, gateway, and origin in a single command. Built from operating OHTTP at millions of requests per second, it gives engineers a way to debug the multi-party encryption and binary HTTP flows behind services like Apple Private Relay without wiring up custom clients.

What’s Hiding in Your Mobile Apps? Lookout MSEC Aims to Find Out (1 minute read)

Lookout launched Mobile Security Exposure Center (MSEC), which builds a proprietary SBOM from each app's binary across a device fleet, then correlates the extracted components against vulnerability databases like the KEV list to surface exposures such as vulnerable WolfSSL builds in banking apps. It maps every finding to the affected app version, user, and device, feeding results into the organization's CTEM for remediation.

7AI expands platform with Federated SIEM and AI workflow builder (1 minute read)

7AI added two capabilities to its agentic SOC platform: Federated SIEM, which queries, investigates, and acts on data where it lives instead of ingesting everything into a central SIEM, and 7AI Build, which lets customers and partners define their own agentic workflows, skills, and security services. The platform separates detection from storage and builds a per-customer context graph so agents reason against an organization's actual users, assets, and policies.

C1 adds shadow AI discovery to its identity governance platform (1 minute read)

C1 launched shadow AI discovery for its identity governance platform, scanning both cloud and endpoints to surface unowned AI agents, MCP servers, long-lived keys, over-permissioned service accounts, and API tokens sitting in plaintext .env files. Rather than stopping at a one-time flag, each discovered agent or credential becomes a managed access item with an assigned owner, approval workflow, certification review, and de-provisioning when stale.
