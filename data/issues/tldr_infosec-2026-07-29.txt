Public PoC Released for Exploited Check Point SmartConsole Authentication Bypass (1 minute read)

Rapid7 published a public PoC for CVE-2026-16232 (CVSS 9.3), an authentication-bypass in Check Point's Security Management and MDS servers that lets an unauthenticated attacker replay the server's own SIC DN to mint a SmartConsole SSO ticket with full admin rights. Check Point patched the flaw after zero-day exploitation against a handful of customers; patch immediately and restrict Trusted Clients on any Management Server reachable over the network.

Attackers Exploit Arista VeloCloud Orchestrator Command Injection Flaw (1 minute read)

Attackers are actively exploiting CVE-2026-16812 (CVSS 10.0), an OS command-injection flaw in on-premises Arista VeloCloud Orchestrator that lets a remote attacker reach privileged internal functions and achieve arbitrary code execution on the VCO host. Patch to VCO 5.2.3.14, 6.1.3.4, 6.4.2.4, or 7.0.0.1, block the three attacker IPs Arista published, and rotate credentials on managed VeloCloud Edge devices, which compromise may also expose.

RefluXFS: A Linux Kernel Local Privilege Escalation to Root in XFS (CVE-2026-64600) (5 minute read)

Qualys disclosed CVE-2026-64600 (RefluXFS), a race condition in the Linux kernel's XFS copy-on-write path that lets an unprivileged local user overwrite protected files at the block layer and escalate to host root, even under SELinux Enforcing. The flaw has existed since kernel 4.11, affects default RHEL, Oracle Linux, Amazon Linux, and Fedora installs with reflink-enabled XFS, and has no reliable mitigation, so patch and reboot exposed and multi-tenant systems immediately.

New Gitea RCE Lets Repository Writers Plant a Git Hook to Run Shell Commands (1 minute read)

Gitea patched CVE-2026-60004 (CVSS 9.8), a critical RCE letting any user with repository write access plant a malicious patch that lands an executable at hooks/post-index-change and runs shell commands as the Gitea service account. It affects versions 1.17 through 1.26.x and is fixed in 1.27.1; public PoC code exists, and because open registration is on by default, disabling it or upgrading immediately closes the unauthenticated path on exposed instances.

Mapping CVEs to MITRE ATT&CK Techniques: A Curated Gold-Set Classifier and the Limits of LLM-Assisted Label Expansion (1 minute read)

This paper trains a multi-label classifier to map CVE descriptions to MITRE ATT&CK techniques, using a curated gold set of 1,207 expert mappings that roughly doubles recall@5 over a zero-shot embedding baseline (0.673 with a corrected checkpoint-selection protocol). The authors show that LLM-assisted label expansion yields no reliable gain and can degrade rare-technique coverage, since LLM labels agree with experts only 39% of the time. Automated ATT&CK mapping is bottlenecked by label quality, not dataset size.

Bits and Memories: Measuring Verbatim Extraction Across LLM Quantization (1 minute read)

This paper measures whether quantization removes memorized training data by tracking verbatim extraction, not membership inference, across five precision levels of the Pythia models. Quantization is a selective forgetter, dropping memorization faster than capability, but four-bit compression on the largest model still reproduces most memorized sequences while losing only a few percent of capability. Treat compression as no defense against training-data extraction, and watch extraction rather than membership inference.

SecDrift: Measuring Sector-Conditioned Security Drift in AI-Generated Code (1 minute read)

SecDrift benchmarks whether conditioning code-generation prompts on industry context changes the security of LLM output, running 5,355 evaluations across 7 models, 8 CISA critical-infrastructure sectors, and 9 CWE categories. Sector framing produced no statistically significant drift; the apparent gap was a composition artifact of CWE-502 and CWE-22, and a placebo on non-CISA sectors reproduced the same rate. Model choice was the real lever, with vulnerability rates ranging 11.6% to 16.1%, so pick the model, not the prompt framing.

End-to-End Detection Validation Using Coding Agents (5 minute read)

Most detections held up, but the loop surfaced small pipeline defects that had slipped past code review.

Detecting CSAM Text-to-Image LoRAs From Weights (1 minute read)

This paper introduces a method to detect CSAM-producing LoRA fine-tunes directly from model weights, avoiding the need to trust metadata or generate illegal outputs to test. The top-left singular vector of a LoRA's weight updates forms a compact, inference-free fingerprint that identifies what the adapter was trained on, generalizes across base models, and abstains on benign content. The signal holds up against additive weight noise, rescaling, and precision reduction, suggesting a way to screen harmful adapters before they reach a distribution platform.

Anti-Backdoor Coreset Selection via Cumulative Entropy (1 minute read)

This paper introduces Anti-Backdoor Coreset Selection, a training-time defense that treats isolating clean data from poisoned training sets as a coreset problem. It uses Cumulative Entropy to track per-sample learning dynamics and select high-informativeness benign samples, exploiting the fact that poisoned samples show lower prediction uncertainty and appear less frequently. The authors report consistent backdoor mitigation with negligible loss of natural accuracy, outperforming prior defenses that degrade clean performance or fail against specific attacks.

Hybrid Analysis for Secure MCP Tool Use in LLM Agents (1 minute read)

This paper introduces MTGuard, a hybrid analysis framework that defends MCP tool use in LLM agents by combining static prompt/output inspection with lifecycle-aware dynamic analysis, addressing the blind spots of static-only defenses. The authors report that MTGuard mitigates multiple categories of harmful or unauthorized tool calls across different agents while preserving performance on benign tasks, making it a candidate control for teams already exposing MCP tools to production agents.

We have proof automation now (1 minute read)

Adam Langley argues that proof automation has advanced enough to make dependently-typed verification practical, pointing to a formally verified zstd implementation in Lean as evidence. Formal methods have historically been niche because proof effort dwarfs implementation, with seL4 spending roughly 10x as long proving as designing and shipping 20x more proof code than C. Cheaper proof automation lowers that barrier for security-critical components like parsers and codecs, where verified memory safety and correctness eliminate whole classes of exploitable bugs.

Session revocations at scale (5 minute read)

Canva detailed how it revokes sessions for hundreds of millions of users without hammering its database on every deploy. Gateways trust encrypted session cookies and check a 12-hour in-memory revocation cache per request, but seeding that cache meant every gateway pod pulling over a million records from MySQL on startup, a coordinated stampede. Canva's fix adds a cache layer between MySQL and the gateways to cut both the seeding load and in-memory size.

BioDisclose: An Actionability-Aware Benchmark for Biomedical Safety under Adversarial Elicitation (1 minute read)

BioDisclose is a benchmark measuring how much dual-use biomedical knowledge LLMs disclose under adversarial prompting, grading 480 prompts across six risk domains on a four-level scale from refusal to executable, actionable content. Across five deployed systems, detailed-or-higher disclosure ranged from 9.2% to 64.0%, with academic framing the most effective elicitation (43.2%) and lab-safety scenarios the leakiest domain (51.5%). For teams red-teaming model deployments, it shows binary refusal metrics hide refuse-then-leak behavior and uneven safeguards in high-stakes settings.

The Disruptive Impact of Large Language Models on Capture the Flag Competitions and the Path Toward Fair Play (1 minute read)

LLMs now reliably solve easy and intermediate cryptography, web, and binary exploitation CTF challenges with minimal human input, undermining rankings and the skill development that justifies participation. This paper maps the human-machine capability boundary by category and proposes a four-part safeguard framework: tiered competition divisions, LLM-resistant challenge design, investigative telemetry, and a community code of conduct, tied to each competition's declared purpose. The authors extend the argument to any security context where a demonstrated result stands in for underlying ability.

SafeFlow: Semantic Information-Flow Control for Blocking Malicious Propagation in Multi-Agent Systems (1 minute read)

SafeFlow proposes treating malicious cross-agent propagation in multi-agent systems as a semantic information-flow problem rather than single-turn prompt classification, addressing the blind spot where a harmful goal is split into locally benign subtasks. It attaches structured semantic taints to root requests, propagates them through a dynamic collaboration graph, and runs workflow-level validation before irreversible actions. Across four benchmarks covering prompt injection, jailbreak tool use, risky code execution, and web-agent abuse, it lowered attack success rates while preserving benign task completion.

Characterizing and Mitigating the Effects of Device Temperature on RF Fingerprinting Accuracy (1 minute read)

This paper introduces a temperature-aware RF fingerprinting framework that folds device temperature into the learning process, addressing a blind spot in existing RFFP device-authentication methods where thermal drift alters hardware signatures and degrades classification. Tested on a real-world Bluetooth Low Energy dataset across multiple devices and conditions, the approach consistently beat other temperature-mitigation baselines, with the largest accuracy gains under unseen temperature and environmental conditions.
