Long-Lived Vulnerability in Microsoft Secure Boot (1 minute read)

ESET researchers found that Microsoft Secure Boot has been trivially bypassable for 13 of its 14 years, tracing the flaw to 11 vulnerable shims, at least one dating to 2013, that Microsoft signed and never revoked despite known defects. Because the forgotten shims remain valid in device UEFI firmware, even a novice attacker can load a malicious bootloader and circumvent Secure Boot entirely until Microsoft revokes the offending signatures.

Ruflo MCP Flaw Lets Unauthenticated Attackers Run Commands and Poison AI Memory (1 minute read)

CVE-2026-59726 (CVSS 10.0), dubbed RufRoot by Noma Labs, lets unauthenticated attackers reach an exposed MCP bridge in Ruflo (formerly Claude Flow) and invoke any of 233 tools, including shell execution, via a single HTTP POST to port 3001. Upgrade to 3.16.3 or later, restrict the default 0.0.0.0 binding, and rotate exposed LLM API keys, since a foothold enables key theft, AI memory poisoning, and persistent backdoors.

Measuring LLMs’ Ability to Perform Cryptanalysis (1 minute read)

CryptanalysisBench tests whether frontier LLMs can discover new mathematical attacks against cryptographic primitives, spanning 191 tasks across six families drawn largely from NIST standardization competitions. Five models broke 65-86% of Tier-1 schemes with known breaks and produced novel results, including a key-recovery attack on the SpoC AEAD and an error in KINDI's published CCA-security proof. Anthropic separately used it to surface new vulnerabilities in Hawk and reduced-round AES, an early signal that AI cryptanalysis is worth tracking as a scheme-vetting tool.

ShutterGap: Aryon Security finds 3.7M AWS cloud resources exposed beyond CSPM/CNAPP visibility (1 minute read)
