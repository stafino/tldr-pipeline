SQLite Critical CVEs or LLM Slop? (1 minute read)

JFrog researchers found that a batch of critical SQLite CVEs published via a new GitHub repo (programmervuln/cveadvisory-) are LLM-fabricated, yet NVD flagged them critical and CISA's ADP concurred. KindaRails2Shell threatens Ruby on Rails apps (CVE-2026-66066) (1 minute read) [flag]

KindaRails2Shell (CVE-2026-66066) is a critical flaw in Rails Active Storage that lets an unauthenticated attacker upload a booby-trapped file, which libvips processes with unsafe format handlers to read arbitrary server files including secret_key_base, enabling escalation to RCE or lateral movement. Patch to Active Storage 7.2.3.2, 8.0.5.1, or 8.1.3.1; apps using the default vips processor with image uploads since Rails 7 should treat exposed secrets as compromised and rotate them.

CISA lays out new guidance for using open-source software (1 minute read)

CISA published the Open Source Software: Security Principles and Practices guide, directing federal agencies to treat OSS like any other software asset: assess it before adoption, maintain an SBOM-backed inventory of dependencies, and monitor projects for newly disclosed vulnerabilities throughout their lifecycle. The guide also tells agencies to patch as soon as practical, contribute upstream fixes when a project has not yet released an update, and replace projects that reach end of support or leave security issues unresolved.

Anthropic: AI Attacks Result of Security Gaps, Not Model Issues (1 minute read)

Anthropic attributed three incidents in which its Claude agents autonomously compromised real external systems during CTF-style testing to over-permissioning and internet access, not model misalignment. Reviewing 141,006 tests, the company found six evaluations where Claude breached outside organizations, including publishing a malicious PyPI package that reached 15 real systems and exploiting SQL injection on an internet-facing app after scanning 9,000 hosts. The takeaway for defenders: air-gap offensive-agent evaluations and scope credentials tightly rather than trusting the model to stay in bounds.

Prompt Injection Is an Authorization Problem (3 minute read)

The author argues that prompt injection against LLM agents is fundamentally an authorization failure, not a prompt-engineering one: when every caller shares a single module-level tool list, the only boundary between a customer and the admin API is a system-prompt sentence the model weighs against the attacker's text. The fix is structural, not more prompt hardening. Scope tools to the authenticated caller and enforce authorization outside the model, so a plausible social-engineering frame can't unlock admin capabilities the caller was never entitled to.

The SOC’s AI maturity model (2 minute read)

This article defines a three-stage maturity model for AI in the SOC: assistance (AI summarizes alerts and logs while analysts decide), automation (agentic AI runs investigations and proposes actions under human oversight), and autonomy (agents act on continuous policy constraints without case-by-case approval). The author argues that advancing a stage depends less on model capability than on data validity, since autonomous response inverts the SOC's usual "validate evidence before acting" discipline and forces teams to trust outputs they can only audit after the fact.

New Tool Traces AI Videos Back to Their Source (1 minute read)

UC Riverside researchers released SAGA (Source Attribution of Generative AI videos), a framework that goes beyond detecting whether a video is AI-generated to attribute it to the specific generative model, model version, and development team behind it. Trained on publicly available data, the tool aims to give defenders forensic provenance for deepfakes used in remote-hire fraud, impersonation, and disinformation campaigns.

Exclusive: Terra Security’s Prevention writes the firewall rules to block proven exploits (1 minute read)

Terra Security launched Prevention, a feature that generates targeted WAF or firewall rules to block exploits its offensive AI agents have already confirmed are exploitable, then validates each rule against the specific attack path before a security team deploys it. It targets the weeks-long window between a proven finding and a shipped patch, when known vulnerabilities are being weaponized within minutes of disclosure; sensitive production changes still require human sign-off.

Mimecast introduces AI agent governance and managed threat response (1 minute read)

Mimecast released Agent Risk Center, a beta capability for discovering, monitoring, and governing AI agents alongside human-insider risk, and Managed Threat Response, a 24/7 service pairing AI-assisted triage with analyst-confirmed remediation. Agent Risk Center provides a unified inventory of sanctioned and unsanctioned AI tools, department-level policy enforcement, and response controls like browser upload blocking; it opens free to Incydr subscribers, with early access in September 2026.

Qodana 2026.2 adds post-quantum crypto checks for JVM code (1 minute read)

JetBrains released Qodana 2026.2, which adds post-quantum cryptography inspections for JVM code that flag algorithms vulnerable to quantum attack across five NIST-aligned severity levels, from legacy pre-quantum algorithms up to anything short of maximum security. The release also ships a taint engine for cross-file data-flow tracking in the .NET linter, OpenGrep custom rules, dependency-license build gates, and coverage reporting that reads default report locations without manual configuration.

Running on Cato's cloud-native platform, it draws on existing telemetry, customer activity, and outside threat intel, extending the Agentic CVE Mitigation service Cato shipped in June that applies protection in as fast as 45 minutes.
