Coldcard Hardware Wallet Flaw Linked to $70 Million Bitcoin Theft in 41 Minutes (1 minute read) [flag]

A Coldcard firmware flaw let an attacker drain 1,082.65 BTC (about $70.2 million) from 1,196 addresses in 41 minutes on July 30, after a March 2021 integration error routed seed generation to a deterministic PRNG instead of the STM32 hardware RNG, cutting effective entropy to roughly 40 bits on Mk3 and 72 on later models. Coinkite shipped emergency firmware on July 31, but patching does not fix an existing seed, so exposed owners must generate a new seed and move their coins.

Hugging Face Diffusers Flaws Could Let Model Repositories Execute Arbitrary Code (1 minute read)

Three high-severity flaws collectively named FaceHugger in Hugging Face's Diffusers library (including CVE-2026-44827, CVSS 8.8) let crafted model repositories execute arbitrary code by bypassing the trust_remote_code safeguard via TOCTOU races in the two-request model download. With Diffusers downloaded 8.1M times in July and embedded in production pipelines, CI/CD, and container images, teams should upgrade and treat untrusted Hub repos as executable code.

Researchers used AI-assisted code to undetectably tamper with data from computerized scans of physical DNA evidence produced by widely used crime-lab machines (Mariah Timms/Wall Street Journal) (1 minute read)

Researchers demonstrated AI-assisted code that undetectably alters the digitized output of DNA-analysis machines used by crime labs, corrupting scan data in ways that leave no forensic trace and could implicate or exonerate the wrong person. The attack targets the software layer between the sequencing hardware and analyst review, so labs should validate instrument output integrity with cryptographic checksums and audit the acquisition pipeline rather than trusting raw exports.

N-able Says Attackers Take Over N-central Servers After Initial Fix Proves Incomplete (1 minute read)

Attackers are exploiting an authentication bypass in N-able N-central (CVE-2026-18577, CVSS 8.2) to gain remote administrative access to servers and the customer endpoints they manage, and N-able's initial 2026.3 fix proved incomplete. Upgrade to build 2026.3.1.7, then hunt managed endpoints for attacker-installed Cloudflare tunnel services, which run as services to survive reboots and persist even after N-central access is revoked.

Adobe Campaign Classic CVSS 10.0 Flaw Could Run Code Without User Interaction (1 minute read)

Adobe patched a maximum-severity incorrect-authorization flaw in Campaign Classic (CVE-2026-48449, CVSS 10.0) that allows arbitrary code execution in the current user's context with no user interaction, alongside a SQL injection bug (CVE-2026-48448, CVSS 8.6) enabling arbitrary file reads. Fixes ship in ACC v7 7.4.3 build 9398 for Windows and Linux, and Adobe reports no in-the-wild exploitation so far.

Ruby on Rails Patches Critical Vulnerability (1 minute read)

Ruby on Rails patched CVE-2026-66066 (CVSS 9.5), a default-configuration arbitrary file read in Active Storage that lets unauthenticated attackers exfiltrate secret_key_base and external credentials, then escalate to RCE. The flaw affects apps using libvips for image processing that accept untrusted uploads; patch Active Storage to 7.2.3.2, 8.0.5.1, or 8.1.3.1, upgrade libvips to 8.13+, and rotate every secret readable by the app process.

CISA Alert: Water Sector PLC Targeting (1 minute read)

CISA warned on July 30, 2026 that threat actors are increasingly compromising internet-exposed PLCs in the Water and Wastewater sector, changing passwords to lock out operators and altering device IPs to force boil-water notices and manual operations. Utilities running Rockwell/Allen-Bradley, Siemens, or Schneider Electric controllers should pull PLCs off the internet, route remote access through a VPN, and audit undocumented cellular modems that routine attack-surface scans miss.

Rails patches critical Active Storage flaw with RCE potential (1 minute read)

Rails patched CVE-2026-66066, a critical Active Storage flaw that lets an unauthenticated attacker upload a crafted image to read arbitrary files, including secret_key_base and database credentials, with potential escalation to RCE. Exploitation requires libvips (the default in official Rails Docker images and Debian/Ubuntu) and untrusted image uploads; maintainers published full details early after public PoCs appeared, so patch to the fixed Active Storage releases and rotate all exposed secrets.

Iran suspected of conducting cyberattacks on US water suppliers in 45 municipalities — small towns mostly targeted, with utilities switching to manual control (1 minute read)

Suspected Iranian threat actors targeted water-supply control systems across 45 municipalities in seven states, prompting utilities in small towns like Braham, Minnesota to revert to manual control. The attackers made no financial demands and caused no confirmed drinking-water safety impact, but defenders should prioritize isolating internet-connected SCADA and monitoring systems that adjust chemical treatment and water pressure on aging, unpatched infrastructure.

Rooting, firmware analysis and persistent credentials of TP-Link TL-841N (1 minute read)

A security researcher documented the full hardware-hacking chain against a $10 TP-Link TL-841N router, extracting firmware via both UART/TFTP and chip-off flash dumping, unpacking the SquashFS root filesystem, and gaining a root shell. The filesystem analysis surfaced plaintext hardcoded credentials from the previous owner, at least one of which persisted through a full factory reset, underscoring the resale and disposal risk in consumer IoT gear.

AI is 'both the weapon and the target' in latest wave of cyberattacks (1 minute read)

AI now sits on both sides of the attack chain, serving as the tooling that accelerates intrusion campaigns and as a target set of its own as organizations wire LLMs and agents into production. Defenders should extend existing controls to cover AI infrastructure, treating model endpoints, prompt pipelines, and agent tool access as attack surface subject to injection, data exfiltration, and abuse. The practical takeaway is to inventory where AI touches sensitive systems and apply the same authentication, logging, and least-privilege discipline used elsewhere.

Mapping the malware blast radius a single alert won’t show you (1 minute read)

Stairwell launched Backstory, an agentic investigation platform that takes a single SOC alert and works outward to map a malware campaign's full blast radius, finding structurally related variants, tracing shared infrastructure, and searching endpoint history to identify every affected system. Founder Mike Wiacek cites Stairwell research that each published sample hides an average of 2.4 undocumented variants, arguing that alert-and-close triage leaves the bulk of a campaign undetected as attackers ship AI-generated variants at scale to evade signature-based defenses.

Californians' data deletion requests, DROP, become enforceable Aug. 1 (1 minute read)

California's Delete Request Opt-out Platform (DROP) became enforceable on Aug. 1, requiring the state's roughly 600 registered data brokers to honor consumer deletion requests within 45 days or face fines of $200 per day per affected resident. About 350,000 Californians have signed up since January to submit a single request that removes their personal data across all registered brokers instead of contacting each one individually.

Defcon's new badge is a security key you can see inside (1 minute read)

Defcon commissioned hardware hacker Andrew "bunnie" Huang to build this year's badge around the Baochip-1x, a mostly open source microcontroller three years in the making whose OS, firmware, processor core, and crypto engines are published on GitHub for inspection. The badge's core module detaches into a reusable hardware security token, and the chip is packaged so researchers can inspect the silicon directly and verify it matches the published design.
