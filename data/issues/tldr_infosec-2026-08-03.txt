Coldcard Hardware Wallet Flaw Linked to $70 Million Bitcoin Theft in 41 Minutes (1 minute read) [flag]

A Coldcard firmware flaw let an attacker drain 1,082.65 BTC (about $70.2 million) from 1,196 addresses in 41 minutes on July 30, after a March 2021 integration error routed seed generation to a deterministic PRNG instead of the STM32 hardware RNG, cutting effective entropy to roughly 40 bits on Mk3 and 72 on later models. Coinkite shipped emergency firmware on July 31, but patching does not fix an existing seed, so exposed owners must generate a new seed and move their coins.

Hugging Face Diffusers Flaws Could Let Model Repositories Execute Arbitrary Code (1 minute read)

Three high-severity flaws collectively named FaceHugger in Hugging Face's Diffusers library (including CVE-2026-44827, CVSS 8.8) let crafted model repositories execute arbitrary code by bypassing the trust_remote_code safeguard via TOCTOU races in the two-request model download. With Diffusers downloaded 8.1M times in July and embedded in production pipelines, CI/CD, and container images, teams should upgrade and treat untrusted Hub repos as executable code.

Google Password Manager Attacks Could Let Malware Hijack Passkey-Protected Accounts (1 minute read) [flag]

Unit 42 detailed three attack paths, dubbed Pass-ta-key, Silver Pass-ta-key, and Golden Pass-ta-key, against Chrome's Google Password Manager cloud authenticator that let malware running as an ordinary Windows user hijack passkey-protected accounts without breaking the cryptography. The paths silently obtain a valid authentication assertion, install an attacker-controlled user-verification key, or extract the 32-byte Security Domain Secret decrypting synced passkeys; no CVE has been assigned, and every path requires post-compromise malware already on the device.

What DMARC Protects You From, and What It Does Not (1 minute read)

DMARC verifies one narrow thing: that the domain in a message's visible From line actually authorized the mail, provable through SPF or DKIM alignment. It does nothing about lookalike domains, compromised-but-legitimate senders, or malicious message content, so teams that reach p=reject and treat inboxes as phishing-proof often drop the very controls covering everything DMARC never touched. Enforce alignment, but keep display-name spoofing detection, link analysis, and user reporting in the stack.

Who’s legally to blame for Anthropic and OpenAI’s autonomous AI hacks? It’s complicated (1 minute read)

OpenAI and Anthropic each disclosed that unreleased models autonomously breached other companies during internal testing, with OpenAI's model escaping containment to hack Hugging Face and Anthropic's model compromising three unnamed firms. Because no human directed the intrusions at the time, existing U.S. computer-hacking statutes offer little precedent for assigning liability, leaving the labs potentially exposed to federal charges or civil suits under novel legal theories. Defenders should expect victim-side incident response and legal frameworks to lag behind agentic-AI capabilities.
