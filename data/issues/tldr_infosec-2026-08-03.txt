KindaRails2Shell threatens Ruby on Rails apps (CVE-2026-66066) (1 minute read) [flag]

KindaRails2Shell (CVE-2026-66066) is a critical flaw in Rails Active Storage that lets an unauthenticated attacker upload a booby-trapped file, which libvips processes with unsafe format handlers to read arbitrary server files including secret_key_base, enabling escalation to RCE or lateral movement. Patch to Active Storage 7.2.3.2, 8.0.5.1, or 8.1.3.1; apps using the default vips processor with image uploads since Rails 7 should treat exposed secrets as compromised and rotate them.

The SOC’s AI maturity model (2 minute read)

This article defines a three-stage maturity model for AI in the SOC: assistance (AI summarizes alerts and logs while analysts decide), automation (agentic AI runs investigations and proposes actions under human oversight), and autonomy (agents act on continuous policy constraints without case-by-case approval). The author argues that advancing a stage depends less on model capability than on data validity, since autonomous response inverts the SOC's usual "validate evidence before acting" discipline and forces teams to trust outputs they can only audit after the fact.

Exclusive: Terra Security’s Prevention writes the firewall rules to block proven exploits (1 minute read)

Terra Security launched Prevention, a feature that generates targeted WAF or firewall rules to block exploits its offensive AI agents have already confirmed are exploitable, then validates each rule against the specific attack path before a security team deploys it. It targets the weeks-long window between a proven finding and a shipped patch, when known vulnerabilities are being weaponized within minutes of disclosure; sensitive production changes still require human sign-off.

Mimecast introduces AI agent governance and managed threat response (1 minute read)

Mimecast released Agent Risk Center, a beta capability for discovering, monitoring, and governing AI agents alongside human-insider risk, and Managed Threat Response, a 24/7 service pairing AI-assisted triage with analyst-confirmed remediation. Agent Risk Center provides a unified inventory of sanctioned and unsanctioned AI tools, department-level policy enforcement, and response controls like browser upload blocking; it opens free to Incydr subscribers, with early access in September 2026.

Qodana 2026.2 adds post-quantum crypto checks for JVM code (1 minute read)

JetBrains released Qodana 2026.2, which adds post-quantum cryptography inspections for JVM code that flag algorithms vulnerable to quantum attack across five NIST-aligned severity levels, from legacy pre-quantum algorithms up to anything short of maximum security. The release also ships a taint engine for cross-file data-flow tracking in the .NET linter, OpenGrep custom rules, dependency-license build gates, and coverage reporting that reads default report locations without manual configuration.

Elastic Defend now covers 800+ vulnerable drivers, with automated troubleshooting and ARM support (1 minute read)

Elastic Defend now generates and deploys detection rules for 800+ known vulnerable drivers, closing the BYOVD window where attackers load a Microsoft-signed but flawed driver to gain kernel access and disable endpoint protection. Elastic Security Labs monitors VirusTotal, LOLDrivers, and Microsoft's Vulnerable Driver Block List to auto-build signature-based rules decoupled from the product release cycle; defenders should enable malware protection and set it to Prevent.

Cato Networks launches Agentic Threat Prevention to counter AI-assisted attacks (1 minute read)

Cato Networks introduced Agentic Threat Prevention, which uses autonomous agents to predict an attacker's likely path through a customer's network and generate environment-specific controls before the attack advances. Running on Cato's cloud-native platform, it draws on existing telemetry, customer activity, and outside threat intel, extending the Agentic CVE Mitigation service Cato shipped in June that applies protection in as fast as 45 minutes.
