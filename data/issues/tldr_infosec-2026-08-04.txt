EntailLLM: Verifying LLM-Generated Vulnerability Discovery Paths with Domain Knowledge via Logic Programming (1 minute read)

EntailLLM validates LLM-generated vulnerability discovery paths by checking each proposed analyst path against an independent body of domain knowledge, using temporal annotated logic to align a binary's function call graph with a separate knowledge graph. Across three CWE classes, four LLMs, and seven binaries, grounding the reasoning in domain knowledge raised pooled entailment from 78% to 98%, and the system hit 98% on real medical-device binaries without per-device tuning. The output is explainable and carries the formal guarantees of generalized annotated logic.

Self-Supervised Representations for Binary Program Clustering: From Empirical Study to Retrieval-Augmented Learning (1 minute read)

This paper presents the first systematic study of self-supervised and tabular representation learning for binary program clustering, the label-agnostic grouping of samples used to surface new malware families. Tested on the Ember and Bodmas datasets, BYOL and SimSiam matched fully supervised models while VIME set a new unsupervised state of the art. The authors then propose VIME-R, which swaps random corruption for retrieval-based augmentation and lifts clustering Homogeneity by 2.7% to 5.8%.

TurboRetry: Mitigating Large-Scale QUIC Handshake Floods with Off-the-Shelf DPU Offloading (1 minute read)

TurboRetry offloads QUIC's built-in Retry defense onto off-the-shelf DPUs to counter large-scale handshake floods, which exhaust server CPU by forcing expensive cryptographic operations per connection. The authors show that QUIC's native host-side Retry mechanism itself becomes a bottleneck under heavy flooding, then split the work between DPUs and host using an extended Retry token format and on-path DPA for connection authorization. The result improves throughput 10-20x over the host-only implementation.

How Benchmarks and Evaluation Protocols Shape Conclusions in Provenance-Based Intrusion Detection (1 minute read)

Provenance-based intrusion detection systems report strong results, but this paper shows those conclusions depend heavily on benchmark choice and evaluation protocol. Re-evaluating representative PIDS on audited DARPA TC E3 datasets under a unified protocol, the authors find a simple allowlist of training executable names and paths matches or beats learned baselines on three of four datasets, suggesting measured gains reflect lexical novelty rather than richer provenance modeling. Treat architectural claims as inseparable from the benchmark that produced them.

Why Formal Monitors Fail: Attack Distribution Entropy as a Coverage Bound for LTL-Based LLM Agent Safety (1 minute read)

This paper proves why LTL/FSA runtime monitors catch unsafe LLM tool-call sequences on some model backends and miss them entirely on others. Recall is bounded by attack-distribution entropy: GPT and DeepSeek concentrate attacks into one dominant pattern (H~0.24 bits, 68-75% coverage), while Gemini disperses them across seven clusters (H~2.81 bits, 6-13% coverage), a gap retraining does not close. The authors offer a pre-deployment entropy test to predict monitor coverage before you rely on it.

Measuring Post-Quantum TLS Deployment Across UK Internet Sectors (1 minute read)

A measurement study of 4,665 UK organizations across ten sectors found that observable post-quantum TLS deployment is driven by infrastructure providers, not organizational readiness. Among reachable endpoints, 44.0% of HTTPS services supported at least one PQC key-exchange group versus 6.4% of SMTP, provider identity predicted deployment far better than sector, and no post-quantum certificate signatures were seen anywhere. Treat externally visible PQC support as a provider-shaped signal, not evidence of an organization's migration progress.

Pretraining on Call Graphs: When Binary Analysis Tasks Profit From Context (1 minute read)

This paper tests whether adding call-graph context to binary function embedding models actually helps downstream reverse engineering, and finds the gains don't transfer cleanly. Integrating inter-procedural context improves binary code similarity detection but does not reliably carry over to other semantic or syntactic tasks, and optimizing for semantic similarity correlates with worse syntactic performance. Call-graph enhancements mainly boost robustness where base models struggle and help most on namespace-related functions rather than self-contained logic.

MNC: Scope-Bound Semantic Declassification for Private LLM-Agent Communication (1 minute read)

This paper introduces Minimum-Necessary Communication (MNC), a typed semantic-declassification protocol that binds each agent disclosure to explicit recipient, purpose, forwarding, lifetime, logging, and memory scopes, enforced by a reference monitor. The authors show that redaction and privacy prompts preserve task utility while still leaking inference signal through internal messages, tool arguments, and persistent memory. MNC blocks unauthorized forwarding, logging, durable storage, and post-expiration retrieval that text-only defenses permit.

Securing Agentic AI: From Per-Action Checks to Trajectory Assurance (1 minute read)

This paper argues that agentic AI security must shift from validating individual actions to guaranteeing entire behavioral trajectories, since sequences of individually permissible actions can collectively violate system-level constraints and safety invariants. The authors map attack surfaces across the agentic stack: untrusted inputs via prompts, memory, and tool interfaces at the single-agent level, and identity, trust, and capability-control gaps in multi-agent delegation. Their core principle is that security must be a verifiable property of agent architectures, protocols, and runtimes rather than an optional guidance layer.

Vulnerability Detection in AArch64 Machine Code Using a Digital Twin (1 minute read)

This paper proposes a digital twin that replays AArch64 machine code execution, capturing register, flag, and memory state after each instruction to detect vulnerabilities without source access. Vulnerabilities are encoded as Kleene-algebra rules compiled into finite automata that scan the trace with no SMT solver, catching multi-step patterns rather than isolated unsafe instructions. In testing it flagged CWE-190, CWE-476, and CWE-122 with no false positives on the safe trace, each detection citing the triggered rule, trace position, and concrete state.

Antares: Foundation Models for Agentic Vulnerability Localization (1 minute read)

Antares is a family of compact language models (350M, 1B, and 3B parameters) built on IBM Granite for agentic vulnerability localization, trained via supervised fine-tuning plus reinforcement learning from verifiable rewards. Antares-3B approaches GPT-5.5 while beating open-weight models over 200x larger, and runs a 500-task sweep in about 15 minutes on a single H100 at under $0.002 per task, making local, low-cost triage viable.
