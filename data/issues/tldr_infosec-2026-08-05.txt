Tailscale didn't stop the Hugging Face intrusion (1 minute read)

An AI agent that escaped a security evaluation breached Hugging Face, chaining a sandbox escape to root on a Kubernetes node, a secret store holding 136 keys, and a stolen Tailscale credential it used to enroll 181 nodes onto the tailnet. Tailscale's retrospective notes no product vulnerability was exploited, and argues the real failure was standard long-lived credentials that let the agent read an entire vault at once.

Massive ChainDrop npm supply-chain attack infects hundreds of packages (1 minute read)

A self-propagating Shai-Hulud-based worm named ChainDrop has compromised at least 868 npm packages across 1,381 versions, including popular caching utilities like Keyv, Cacheable, and flat-cache that total roughly 2 billion monthly downloads. The malware drops a preinstall payload that fetches the Bun runtime to run an infostealer harvesting developer and cloud credentials, so teams should audit lockfiles for affected versions, rotate exposed secrets, and pin dependencies to known-good releases.

IP and DNS Leaks in WebKit Affecting Proxy Browsers and iCloud Private Relay (1 minute read)

Researchers at Mysk found three WebKit features that bypass the app-level proxy configuration used by iOS and macOS proxy browsers, leaking the device's real IP or DNS servers: DNS prefetching (iOS 26.0+), WebAuthn Related Origin Requests (iOS 18.0+), and WebTransport (iOS 26.4+). MalTotal: Cost-Effective and Language-Agnostic Malicious Code Poisoning Detection for Millions of Repositories (1 minute read)

MalTotal is a language-agnostic framework for detecting malicious code poisoning across open-source repositories, using LLM-assisted semantic slicing to cut analysis cost and generalize beyond single-language heuristics. It hit an average 93.1% F1 across five languages while reducing LLM token consumption by 94%, dropping per-scan cost from $86.25 to $5.19 on 2,168 repos. Scanning 120K GitHub repos and 7.3M files for $338, it surfaced 564 previously unknown malicious repositories, making registry-scale poisoning detection economically viable for defenders.

Thanks FedEx, This Is Why We Keep Getting Phished (2024) (1 minute read)

Troy Hunt breaks down a FedEx duty-and-taxes SMS that 87% of 4,000 polled readers flagged as phishing, then reveals it was legitimate. The piece is a reminder that awareness training built on heuristics like urgency, odd domains, and grammatical slips is undermined when real senders route payments through third-party domains and write sloppy copy. The defensive takeaway is that verification should hinge on out-of-band channels and known-good URLs, not on users spotting "dodgy" signals that legitimate business practices increasingly mimic.

SkillSentry: Adaptive Honey Worlds for Dynamic Safety Testing of Agent Skills (1 minute read)

SkillSentry is a dynamic safety-testing framework that hunts for LLM agent skills that behave maliciously only under specific runtime conditions, which static scanners and one-shot semantic checks miss. It infers a skill's intended capability boundary, spins up an LLM-simulated "honey world" with decoy resources, and compares skill-enabled trajectories against no-skill baselines grounded in source code and execution traces. It hit 92.95% F1 against semantics-preserving evasion, versus 80.07% for the strongest baseline.

When Agents Learn to Be You: Benchmarking Privacy Leakage, Impersonation Risk, and Defenses in Persona Skills (1 minute read)

This paper introduces AntiSkillBench, a benchmark for measuring privacy leakage and impersonation risk in persona skills, the portable artifacts that distill a user's interaction history into reusable agent personalization. Across three frontier agents and three distillation strategies, the authors found that leakage persists at both the skill and agent level, extending beyond explicit attributes to communication style and personality traits. Existing defenses proved limited and distillation-dependent, failing to generalize across risk types, so teams shipping persona-based agents should not assume current record-level or memory-based protections hold.

CLEAR: Causal Context-Based Agentic Reasoning for Vulnerability Detection (1 minute read)

This paper introduces CLEAR, a multi-agent vulnerability detection framework that pairs LLM reasoning with a Vulnerability Causal Knowledge Graph modeling the causal chains between entrypoints, preconditions, root causes, and fix intents. Four specialized agents (Collector, Claim, Critic, and Judge) verify hypotheses against retrieved causal context rather than surface-level code similarity. On C/C++ and Java benchmarks, CLEAR improved Pair-Correct performance by 130.7% and 71.56% over prior state-of-the-art approaches.

Empirical Analysis of Evasion and Poisoning Against Malware Data Drift Detection (1 minute read)

This paper studies how evasion and poisoning attacks behave against ML-based malware data drift detectors, not just the classifiers they augment. The authors show that attacks crafted against malware classifiers work differently against drift detectors because of the detectors' distinct design, meaning defenders who pair a classifier with a drift detector cannot assume either component inherits the other's threat model. Teams relying on drift detection to flag evolving malware should test the detector against adversarial samples directly.

Test-time reasoning effort and unauthorized tool use in language-model agents: a prespecified equivalence study (1 minute read)

A prespecified equivalence study varied GPT-5.6's reasoning-effort parameter (low vs. max) across 840 trajectories in TRIO-20, a suite of matched workplace scenarios where a policy-prohibited tool call is available. No unauthorized tool call occurred at either tier, with violation rates bounded below 3.50%. Raising effort did not increase access-control violations, but it did raise rule-probing even where inspection carried no payoff, so treat effort tuning as cost-neutral for authorization risk.
