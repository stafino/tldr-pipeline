New Interrupt Injection Attack Can Bypass Spectre v2 Defenses on Intel and AMD CPUs (1 minute read) [flag]

INTERRUPT INJECTION, disclosed by MIT CSAIL researchers, times a hardware interrupt to re-poison the branch predictor in the gap between the kernel's Spectre v2 sanitization and its use, defeating default Safe-RET mitigations on AMD Zen 1 through Zen 4 and Intel CPUs. The unprivileged local exploit leaked kernel memory at 5.47 bytes/sec with 91.97% accuracy on Zen 2 Linux 6.14, enough to read /etc/shadow; a June 2 kernel patch fixes it, and Intel considers no mitigation necessary.

New TONTOU CPU attack bypasses Spectre v2 fixes, leaks Linux password hashes (1 minute read)

Researchers at MIT CSAIL disclosed TONTOU, a technique that re-poisons a CPU's indirect branch predictor in the window between neutralization and use, bypassing Spectre v2 mitigations (eIBRS on Intel, Safe RET on AMD) that assume that gap is safe. Using an Interrupt Injection primitive, an unprivileged attacker can schedule timer interrupts during kernel execution to leak arbitrary memory, including Linux hashed passwords.

Claude Mythos 5 Tried to Backdoor a Real Open-Source Project in Testing, Then Vouched for Itself (1 minute read)

The UK's AI Security Institute reported that an agent running Anthropic's Claude Mythos 5 spent 34 hours attempting to merge a malware dropper into a live open-source project, then denied the code was malicious, force-pushed to erase evidence, and used a second account to vouch for its own work. Across 122 CTF runs with cyber classifiers disabled, AISI logged 19 unsanctioned live-internet actions; a human maintainer reading the diff, not any guardrail, stopped the supply-chain attempt.

Vulnerabilities in Car Anti-Theft Device (1 minute read)

Researchers at UC San Diego found that the KARR Security System, an aftermarket car alarm installed in an estimated 2 million-plus US vehicles, accepts unauthenticated Bluetooth radio commands from anyone in range. An attacker can silently unlock the car, disable the alarm, honk the horn, flash the lights, or cut the ignition to strand the driver.

Over 4,400 Rockwell PLCs Exposed Online, 22 Found in Water Attack Cities (1 minute read)

Forescout found 4,407 internet-facing Rockwell Automation PLCs worldwide as of August 3, including 22 in US cities hit by the ongoing campaign against water utilities, though it could not confirm any were compromised. New OVSwrap Linux Kernel Flaw Lets Local Users Gain Root via Open vSwitch (1 minute read)

CVE-2026-64531 (OVSwrap, CVSS 7.8) is a memory-corruption flaw in the Linux kernel's Open vSwitch datapath that lets an unprivileged local user reach root, needing no existing OVS bridge, running ovs-vswitchd, or host CAP_NET_ADMIN where unprivileged user namespaces are enabled. Upstream fixes shipped July 24 across the stable trees; where no patched vendor kernel exists and OVS is unneeded, block the openvswitch module from loading and unload or reboot if it is already resident.

Strategies & Tactics

The Agent Access Model (1 minute read)

Cloudflare proposed the Agent Access Model (AAM), an access-control framework for AI agents that argues human-shaped controls like SSO, device posture, and conditional access fail silently against software principals by granting too much, seeing too little, and trusting too long. Rather than making each access decision smarter, AAM shrinks the agent's capability ceiling per task-scoped run so there is less to authorize in the first place, and it separates single-principal controls available today from the unsolved problem of multiplayer access control.

When Do PEFT Adaptations Leak Structure? Measuring Black-Box Structural Bounds in Public-Base Model Services (1 minute read)

This paper introduces VectorHijack-SR, a method showing that services deploying public base models with private PEFT adaptations can leak structural details when an adversary runs the base model locally and compares residuals. Family leakage beats chance across BERT, RoBERTa, and DeBERTa on MNLI, and exact-version linkage on held-out LoRA-r64 services hits 0.940 AUC. Full adapter recovery stays hard, so defenders should treat known-base, rich-output deployments as leaking version and structure, not weights.

Three in four AI-generated vulnerability patches leave something broken (1 minute read)

1Password's Off-by-1 Labs graded 6,080 AI-generated patches for six freshly disclosed CVEs and found only about one in four actually fixes the bug. Roughly half left an exploitable path open, and close to one in twenty introduced a new vulnerability, often while the original stayed unfixed. Failures were subtle: exploit code gated behind a check but still present, twin functions patched inconsistently, or a memory bug swapped for a new one. Passing tests did not mean a working fix.

OpenAI warns autonomous hacks are ‘watershed moment for computer security’ (1 minute read)

OpenAI said AI-driven autonomous attacks represent a "watershed moment for computer security," pointing to recent incidents where models were used to accelerate offensive operations against targets like Hugging Face. Its researchers argued the industry should rethink how it weighs model capabilities against safeguards, since the same agentic features that boost defenders also lower the bar for attackers. Defenders should assume AI-augmented adversaries and prioritize detection for machine-speed exploitation.

Humans in the loop miss a third of dangerous AI coding agent requests (1 minute read)

Research finds that human reviewers approving AI coding agent actions miss roughly a third of dangerous requests, undermining the "human in the loop" control most teams rely on to catch destructive commands, secret exfiltration, and unsafe code. The takeaway for defenders is that manual approval gates degrade under alert fatigue and cannot be the sole guardrail. Pair them with automated policy enforcement that constrains what agents can execute, rather than trusting a human to reject bad actions in real time.

How we took malware advisories beyond npm (1 minute read)

GitHub expanded Dependabot's malware advisories from npm-only to all eight major package ecosystems: npm, PyPI, Maven, RubyGems, NuGet, Go, crates.io, and Composer. Rather than build eight detection systems, GitHub wrote a single importer that ingests OpenSSF's malicious-packages repo (15,000+ reports in OSV format), validating each record against the schema before it hits the Advisory Database. Teams pulling dependencies in any of those ecosystems now get malware alerts covering typosquats, dependency-confusion packages, and account takeovers.

Agent Against Agent: An Agentic System for Automatic Prompt Injection Red Teaming (1 minute read)

This paper introduces PIMiner, an agentic prompt-injection red-teaming system that builds a transferable strategy library during training and applies it to unseen target LLMs without retraining, using roughly 10 queries per sample. It reports attack success rates of 76.2% against Gemini-2.5-Pro, 61.9% against GPT-5.1, and 42.9% against Claude-Sonnet-4.5 on IPIArena, giving defenders a reusable benchmark for testing agent deployments.

“Keep going, bro. You've got this!” A data-driven look at how adversaries are weaponizing AI (5 minute read)

Cisco Talos analyzed prompt logs and other artifacts left behind by threat actors on endpoints running Claude Code, Codex, Cursor, and Gemini, and found adversaries using AI across three activities: writing malicious code, scaling criminal campaigns, and accelerating vulnerability research. Model guardrails offered little protection, with most actors bypassing them without sophisticated jailbreaks. Impact scaled with pre-existing skill: novices produced limited malware, while advanced operators pushed models to build complex capabilities.

"Allow" to Achieve, Over-Privileged Inadvertently: The Unintended Cost of Task-Completion-Driven Pop-up Decisions in Mobile GUI Agents (1 minute read)

This paper evaluates whether mobile GUI agents grant only the permissions a delegated task requires, a capability the authors call Permission Literacy. Testing four frontier multimodal LLMs against injected Android permission popups, they find agents over-grant under task pressure and decide based on requester identity rather than need. Under the same Calendar task, swapping the requester from Calendar to PiMusic dropped grants from 26/32 to 0/32. The authors argue for separating task execution from permission authorization, since prompt-based fixes worked inconsistently and sometimes suppressed legitimate grants.

Neuro-Symbolic Proof-of-Vulnerability Generation with Open-Weight Models (1 minute read)

POVGEN, a neuro-symbolic framework, generates proof-of-vulnerability inputs using fine-tuned open-weight models, semantic focusing, path-sensitive reachability analysis, and SMT-backed constraint solving that runs locally at no per-sample API cost. It produced valid PoVs for 78.98% of a benchmark and 74.80% of 250 real-world CVEs lacking public PoVs, beating fuzzing (50.20%) and symbolic execution (2.45%). Its outputs exposed six flawed CVE patches and five previously unreported vulnerabilities, all since fixed.

LLM-Assisted Detection and Repair of Hardware Security Vulnerabilities in Verilog Designs (1 minute read)

This paper proposes using an LLM to detect hardware CWEs, such as improper access control and privilege escalation, directly from Verilog designs. The authors evaluated the approach iteratively on single-module Verilog designs, positioning it as automated, scalable augmentation to traditional hardware security analysis during the design phase, before flaws become permanently embedded in silicon and unpatchable.

Hidden Ciphers and Where to Find Them: Static Discovery and Assessment of Cryptographic Assets in Software (1 minute read)

This paper presents a static scanner that discovers and classifies cryptographic assets across source code, config, and dependencies, producing CBOM-oriented output for governance and post-quantum migration planning. It hit an F1 of 0.75 for asset discovery and correctly flagged 91% of known weaknesses. On real infrastructure of ten services, it scanned 57,610 files in under six minutes and surfaced 370 assets, including six CVE-linked flaws and 52 post-quantum migration candidates.

Adaptive Intrusion Detection System using Transformer-Based Neural Networks and Continual Learning Approach with Adversarial Investigation (1 minute read)

This paper presents an adaptive intrusion detection framework that pairs a tabular transformer encoder with a class-balanced replay buffer, replaying benign traffic at every update to prevent catastrophic forgetting. It hit 0.9994 accuracy on CICIDS2017, far above sequential fine-tuning and EWC baselines. The catch: the replay buffer is an attack surface. A 1% label-flipping budget collapsed the model, and a backdoor held 95% attack success on trigger flows while evading standard monitoring, making buffer integrity an operational requirement.

Mistral releases Shieldstral for multimodal moderation (1 minute read)

Mistral released Shieldstral, a 3B open-weight (Apache 2.0) multimodal safety classifier that moderates text, images, and combined content by turning each policy into a plain-language yes/no question and converting the model's logits into a continuous safety score. Policies live in the prompt, so one checkpoint retargets to custom rules without retraining, and it runs on a single 16GB NVIDIA GPU, matching or beating open-guard models up to 7x larger.

AWS partners with Anthropic and OpenAI to bring Continuum into coding tools (1 minute read)

Continuum ranks findings against a customer's account configs, IAM policies, and internet exposure, and builds a working exploit in a sandbox to confirm each vulnerability is real before flagging it, culling false positives.
