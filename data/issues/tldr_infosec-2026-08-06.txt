Critical Cisco IMC bug gives attackers root, PoC is out (CVE-2026-20200) (1 minute read)

Cisco patched CVE-2026-20200, a critical input-validation flaw in the Cisco IMC web interface that lets an authenticated, low-privilege remote attacker execute arbitrary commands as root on UCS C-Series rack and S-Series storage servers. A public proof-of-concept exploit is already available and no workarounds exist, so operators running affected IMC releases should apply the August 5 fixed versions and restrict management-interface access immediately.

CryptoJS Weak RNG Behind $5.7 Million in Drains Affects Five Crypto Wallet Apps (1 minute read)

Coinspect traced roughly $5.7 million in wallet drains to CryptoJS.lib.WordArray.random(), a 12-year-old function whose weak entropy collapsed 128- and 256-bit recovery-phrase search spaces to about 2^39 and 2^47, enumerable on ordinary hardware. Five apps used it as a seed source (RRWallet, Bexo, NanChat, Bitcoin Libre, Milo); any phrase from an affected build stays guessable even in hardware wallets, so users must generate a new seed and move funds.

AI Recommendation Poisoning: How "Ask AI" Buttons Silently Alter LLM Memory (1 minute read)

Microsoft Security catalogued AI Recommendation Poisoning, a prompt-injection technique in which "Ask AI" buttons on marketing and comparison pages use pre-filled deep links to silently execute commands in a logged-in user's ChatGPT, Claude, Gemini, or Grok session. Tracked as MITRE ATLAS AML.T0080 (Memory Poisoning), the payloads instruct the LLM to save the vendor's domain as a trusted source, biasing future answers across 31 companies observed in production.
