New WordPress Pre-Auth XSS Could Lead to PHP Code Execution - Patch ASAP (1 minute read)

A pre-authentication reflected XSS in the WordPress login screen (CVE-2026-64638, CVSS 8.9) affects every version through the 4.7 branch and requires no attacker privileges, executing attacker JavaScript once a crafted username hits the failed-login error page. pwn.ai chained it to PHP code execution when a logged-in administrator clicks an attacker-controlled page, so patch to WordPress 7.0.3 immediately and confirm automatic background updates applied the August 6 fix.

AI-Assisted HTTP Terminator Finds Novel HTTP Desync Techniques and Apache Zero-Day (1 minute read)

PortSwigger disclosed that HTTP Terminator, an AI-assisted research system built by James Kettle, generated and proved novel HTTP desync techniques after exploring 30,000 candidate vectors, flagging roughly 700 vulnerable targets across banks, government infrastructure, and an airport, plus an Apache Traffic Server zero-day tracked as CVE-2026-63078. Defenders should avoid HTTP/1.1 upstream, and where it cannot be removed, allow-list methods at both proxy layers and restrict which methods may carry request bodies.

CryptoJS Weak RNG Behind $5.7 Million in Drains Affects Five Crypto Wallet Apps (1 minute read)

Coinspect traced roughly $5.7 million in wallet drains to CryptoJS.lib.WordArray.random(), a 12-year-old function whose weak entropy collapsed 128- and 256-bit recovery-phrase search spaces to about 2^39 and 2^47, enumerable on ordinary hardware. Five apps used it as a seed source (RRWallet, Bexo, NanChat, Bitcoin Libre, Milo); any phrase from an affected build stays guessable even in hardware wallets, so users must generate a new seed and move funds.

AI Recommendation Poisoning: How "Ask AI" Buttons Silently Alter LLM Memory (1 minute read)

MIT boffins' TONTOU attack slips through Spectre defenses on Intel and AMD CPUs (1 minute read)

MIT researchers disclosed TONTOU, a speculative-execution attack that bypasses the Spectre mitigations currently deployed on Intel and AMD processors, reviving cross-domain leakage that vendors believed was closed. Defenders should track the affected microarchitectures and forthcoming microcode or kernel updates, since the technique undermines existing hardware-level guarantees and no software workaround short of a vendor patch fully neutralizes it.

Zapscape (CVE-2026-64561): Guest-to-Host Escape in KVM/x86 (1 minute read)

Zapscape (CVE-2026-64561) is a use-after-free in the shadow MMU emulation of KVM/x86 that lets an untrusted guest corrupt the host kernel's shadow page via the recursive zap path and execute code on the host with root privilege. Researcher Hyunwoo Kim published a full PoC chain after the embargo ended, so multi-tenant x86 clouds exposing nested virtualization should patch the KVM host kernel and treat nested-virt guests as a live escape vector.

ChainDrop supply chain compromise: Anatomy of a self-propagating worm (5 minute read)

Microsoft Threat Intelligence linked a large-scale npm supply-chain compromise, dubbed ChainDrop, to a self-propagating Mini Shai-Hulud worm that has poisoned over 400 packages across multiple publishers, including keyv, flat-cache, and cache-manager, executing via preinstall hooks to steal npm, GitHub, AWS, Kubernetes, and Vault credentials. Teams that installed an affected package with lifecycle scripts enabled should treat the workstation or build runner as compromised, and revoke and rotate exposed credentials from a known-clean environment.

Amazon's security team detailed how it defends its own AI systems, treating models as a new attack surface with guardrails against prompt injection, data poisoning, and model abuse layered on top of existing application controls. The playbook leans on automated red-teaming, tight scoping of what models can access, and continuous monitoring of model inputs and outputs. Detecting Safety Training Modification in Language Models via Activation Analysis (1 minute read)

This paper introduces AMS (Activation-based Model Scanner), which detects tampering with a language model's safety training by measuring the geometric structure of safety-relevant concepts in activation space. Across 14 models spanning Llama, Gemma, Qwen, and Mistral, it hit 71% accuracy identifying training removal, abliteration, and refusal-direction rotation, but behavioral-only fine-tunes that preserve activation magnitude and direction remain undetectable. For defenders vetting third-party or open-weight models, activation probing offers a partial provenance check, not a guarantee.

Hardware Keystores for AI Agent Signing Workflows: A Zero-Trust MCP Enforcement Architecture (1 minute read)

This paper proposes confining AI agent signing keys to hardware (HSM, TPM, smart card) via a vendor-neutral PKCS#11 interface, so agents receive only opaque handles and cannot expose raw private keys even when compromised. Hardware confinement sits behind a five-layer Zero-Trust stack (session identity, scope bounds, semantic validation, taint tracking, execution boundary). Tested against 12 AgentDojo-derived injection scenarios, it dropped attack success rate from 19.3% baseline to 0% across three susceptible models, with zero false positives.

Shadow AI in CI/CD: Threat-modeling the path from developer laptop to Kubernetes (1 minute read)

Shadow AI, any AI tool, agent, or integration used in the software lifecycle without approval or monitoring, becomes a security problem when it stops advising and starts acting with a Git token, cloud credentials, or a Kubernetes ServiceAccount. This CNCF post threat-models the path from developer laptop to Kubernetes pod, mapping Shadow AI injection points at each stage to open source controls. Treat every agent as a non-human identity: assign a human owner, register it as a workload, scope least privilege, and monitor its actions.

Behavioral Residualization for Unsupervised Intrusion Detection in Automotive CAN Networks (1 minute read)

This paper introduces per-ID behavioral residualization, a CAN bus representation that extracts fourteen temporal, protocol, and payload features from sliding windows and normalizes them against each arbitration ID's baseline, targeting attacks that reuse legitimate IDs and evade presence-based detectors. Across six unsupervised detectors, it improved mean F1 in most evaluations and hit recall of at least 0.99 on ROAD signal-manipulation attacks, though the authors quantify two blind spots: novel-ID flooding (F1 0.02) and cross-ID fuzzing (F1 0.27).

Robust Context-Aware Detection of Malicious Instructions in Text (1 minute read)

This paper presents a context- and query-aware classifier that segments text into benign and malicious sentences to detect indirect prompt injection in LLM agents. The authors add two adversarial training methods, embedding-space PGD and LLM paraphrasing, that outperform state-of-the-art IPI defenses under both static and adaptive attacks. Optimal robustness settings vary by application domain, so defenders deploying such detectors should tune them per domain rather than expecting one configuration to hold.

Algebraic Cryptanalytic Extraction on Hard-Label Neural Networks (1 minute read)

This paper speeds up hard-label neural network model extraction, the attack that reconstructs a victim model's weights using only its predicted labels. It replaces the SVD-based clustering in Carlini et al.'s EUROCRYPT 2025 attack with an Approximate Signature Vector method using cheap inner products, cutting complexity from O(n²·d³) to O(n·d³), and delivers the first extraction against max-pooling CNNs. Defenders relying on hard-label-only APIs to protect proprietary weights should treat that barrier as weaker than assumed.

Enhancing Anomaly Resilience in Research Networks: A Large-Scale Forecasting Benchmark for Dynamic Security Baselining (1 minute read)

Research and Education Networks face a detection blind spot: their normal "elephant flows" are statistically indistinguishable from volumetric DDoS, driving high false-positive rates that mask real threats. This paper benchmarks six forecasting model families across 960 configurations on a 57-day Internet2 dataset (13.7B packets) to build dynamic anomaly baselines, finding that long-sequence architectures like TiDE cut baseline prediction error 30-42% over traditional methods, sharpening the line between legitimate scientific bursts and attacks.

DreamGuard: Efficient Runtime Guardrail for LLM Agents via Risk-Aware World Model (1 minute read)

DreamGuard proposes a proactive runtime guardrail for LLM agents that uses a risk-aware world model to catch long-horizon threats, where individually benign tool calls gradually drift an agent toward a hazardous state. The model maintains a compact recurrent latent state across the trajectory and predicts future states to derive immediate-hazard and prefix-risk signals before each action executes. Across four benchmarks it beat reactive and proactive baselines on the safety-utility trade-off at an average 25 ms per call.

RustGo: Fairly Directed Greybox Fuzzing for Enforcing Rust Memory Safety (1 minute read)

RustGo is a directed greybox fuzzer that concentrates on unsafe Rust regions rather than fuzzing the whole codebase, since safe Rust's memory safety is already enforced by the compiler. It uses Rust-specific static analysis to identify potential memory-bug targets and prune irrelevant paths, cutting 78.49% of paths on average and reaching targets 2.09x to 5.08x faster than existing fuzzers. Against real-world applications it found 13 previously unknown bugs, yielding six RUSTSEC IDs and one CVE.

ShieldFont fights AI scraping by handing crawlers the wrong words (1 minute read)

ShieldFont is a web font that renders one set of words on screen while leaving different words of the same grammar and frequency in the page source, feeding scrapers, copy-paste, and LLMs ingesting raw HTML a decoy version of the text. The word swap runs at build time on the author's own server, so protected sites keep readable pages while sacrificing some SEO reach, since search crawlers index the decoy too.
