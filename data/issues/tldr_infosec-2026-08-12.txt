OpenAI, Anthropic, Google API Flaw Let Weaker AI Models Decode Stronger Models' Reasoning (1 minute read)

Researchers disclosed a flaw in OpenAI, Anthropic, and Google reasoning APIs where encrypted reasoning blocks could be replayed across sessions and fed to a weaker same-family model to recover hidden reasoning, including API keys and passwords. Across 6,708 public agent trajectories the team decoded 315,320 thinking blocks and 704 privacy artifacts; providers have since deployed mitigations, and developers should strip reasoning fields from shared traces.

Signal’s new security feature checks if your encrypted chats were tampered with (1 minute read)

Signal introduced automatic key verification, which uses key transparency to confirm that a contact's encryption key is consistent across Signal's network and hasn't been silently swapped by an attacker manipulating the key directory. Cloudflare and Trail of Bits independently audit the system so inconsistent key records shown to different users become detectable; verification requires the contact's phone number and does not defend against full account takeover.
