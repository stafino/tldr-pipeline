Hackers Breach Polish Power Plant Controls via Private Cellular Network and Shut Turbine (1 minute read) [flag]

Attackers shut down a steam turbine and process-water treatment system at a Polish combined heat and power plant serving 50,000 residents by pivoting from a compromised wind farm to a WAGO controller over the grid operator's private cellular APN, which CERT Polska calls the first observed real-world use of that vector. The controller ran default admin credentials and the APN permitted client-to-client traffic, so defenders should enable APN client isolation, treat the APN as untrusted from the OT side, and rotate default credentials.

Zoom patched the bugs in June and July, roughly two months before public disclosure, with no exploitation reported and none of the three CVEs listed in CISA's KEV catalog.

From Prompt Injection to Web Exploitation: Revisiting Classic Vulnerabilities in LLM-Integrated Applications (1 minute read)

This paper introduces LLM-mediated web attacks, where attacker input passed through an LLM-integrated app reaches traditional web sinks like SQL, template, and command execution, producing variants such as LLM2SQLi, LLM2SSTI, and LLM2SSRF. The LLM rarely creates the flaw; it acts as a confused deputy carrying attacker influence into components that trust model-generated content. Defenders should treat model output as untrusted input and apply sink-layer controls across the prompt, application, and network.

Activation Probes Surface Code-Security Signals that the Model's Output Misses (1 minute read)

This paper proposes reading an open-weight reviewer model's internal activations, rather than its written verdict, to flag insecure code from AI coding agents. A single linear probe fit on paired vulnerable-and-fixed Python functions scored the vulnerable version higher on 61-67% of held-out real disclosed CVEs across five models, beating both chance and the same model's prompted YES/NO output, which returns identical verdicts for vulnerable and fixed code most of the time.

GitHub already has an EDR. You just have to listen to it (2 minute read)

At Black Hat USA 2026, Microsoft's Yossi Weizman and Echo's Mor Weinberger showed that GitHub's own event stream can serve as EDR-grade telemetry for detecting supply-chain attacks like Shai-Hulud, Trivy, and Megalodon. PQC in Plaintext: Google Cloud’s post-quantum cryptography roadmap (2 minute read)

'GhostJacking' Exposes Identity Governance Gaps in AI Agents (1 minute read)

On the Sensitivity to Errors in Homomorphic Computing: Single Transient Bit-flip Client-side Error Characterization (1 minute read)

This paper analyzes how single-bit faults propagate through Homomorphic Encryption, finding that CKKS-scheme homomorphic multiplication is the most error-sensitive operation and can silently amplify a single transient bit-flip into corrupted output. Because HE relies on noise injection for security, hardware- or software-induced faults evade traditional detection and produce silent data corruption, so teams deploying CKKS for privacy-preserving AI and ML workloads should add fault-tolerance checks around multiplication rather than trusting the pipeline to fail loudly.

A Gateway Architecture for Enterprise MCP Authentication: Unifying Heterogeneous Auth, Identity Delegation, and the User / Non-User Persona Problem (1 minute read)

A new paper reports a production deployment that solves MCP authentication sprawl with a centralized gateway fronting every downstream MCP server. It introduces a two-axis model crossing persona (interactive user vs. automated non-user) with credential type, plus three token-provisioning schemes (bring-your-own-token, generate-your-own-token, and delegated OAuth via RFC 8693 token exchange). For teams that stood up dozens of MCP servers with inconsistent or absent auth, the gateway gives one place to authorize callers, log actions, and offboard departing employees fleet-wide.

Generating Attacks for LLMs with GFlowNets (1 minute read)

This paper introduces a GFlowNet-based red-teaming framework that trains an attacker LLM against a target victim model to generate diverse adversarial prompts and produce a quantitative robustness score. The authors argue the approach yields more varied attacks than fixed-dataset methods, whose creativity is capped by their static inputs, and extend it beyond English to generate attack inputs in Turkish. For teams automating LLM red-team coverage, it points toward adaptive attackers that keep probing as a model hardens rather than replaying a frozen benchmark.

RangeFactory: Scalable Construction of Multi-Hop Cyber Ranges (1 minute read)

This paper introduces RangeFactory, a framework that automatically composes isolated vulnerability environments into validated multi-hop cyber ranges, yielding RangeBench with 1,148 range instances across 287 attack chains for evaluating LLM attack agents. Of runs that compromised the entry vulnerability, 24.5-47.0% still failed to finish the remaining path, exposing a sustained-compromise gap between initial foothold and full chain completion. The work also releases 5,541 outcome-annotated attack trajectories for attack-process analysis and agent training.

STAIR: Effective Incident Response Using an End-to-End Agentic Planning Framework (1 minute read)

STAIR is an agentic incident-response framework that maintains live incident state as a Graph-as-State, routes planning to stage-specialized agents, and retrieves past incidents to guide action selection, replacing the static expert playbooks that fail to adapt to evolving incidents. Across 100 Docker-based cyber ranges it scored 0.94 on normalized defense, 9.5% above the strongest baseline. The work targets long-horizon response, where LLM planners typically drift without a unified basis for tracking state and reusing prior experience.

The Patch Gap: Why Defenders Need to Think in Chains, Not Checklists (1 minute read)

The author argues that CVSS-driven patching is obsolete now that AI vulnerability discovery, exemplified by Anthropic's Claude Mythos, produces flaws faster than any human remediation cycle can clear them. With median time-to-exploit under five days against a 60-day critical remediation average, the piece calls for choke-point patching that breaks attacker chains to critical assets rather than draining the CVSS queue by severity score.

Innocent until combined: Blocking the lethal trifecta with Omnigent Contextual Policies (1 minute read)

Databricks details how Omnigent's contextual policies block Simon Willison's "lethal trifecta," the condition where one agent session combines private-data access, exposure to untrusted content, and an outbound channel that together enable exfiltration. Because per-action authorization checks each call in isolation, they never see the dangerous sequence. The policy instead tracks the three legs as session state and denies the outbound call only once untrusted content and private data are both in play, extending the same model to sub-agents whose instructions are treated as untrusted.

Agentic security: Enterprises enforce agent permissions two-thirds of the time — and isolate high-risk agents less than one in five (3 minute read)

VentureBeat Pulse Research surveyed 116 enterprises on how they secure AI agents and found a containment gap: 65% enforce scoped identities and permissions at runtime, but only 18% isolate high-risk agents in sandboxes, and just 8% pair enforcement with isolation. That ordering is backward for defense-in-depth, since 53% have already logged a confirmed agent security event or near-miss while credential sharing persists across nearly two-thirds of fleets. Prioritize isolation to bound blast radius before autonomy scales further.
