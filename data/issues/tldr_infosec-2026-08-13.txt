Prompt Injections for Defense (1 minute read)

Researchers at Tracebit demonstrated "context bombing," a defensive technique that plants prompt injections alongside AWS-stored secrets like passwords and cryptographic keys to neutralize AI hacking agents. The injected prompts order the attacking LLM to perform guardrail-forbidden actions, such as detailing anthrax weaponization or referencing Tiananmen's Tank Man for Chinese models, causing it to shut down. The tactic only works against agents that carry guardrails, so defenders should expect diminishing returns as attackers shift to locally run models with no safety barriers.

When Agents Talk: Honeytokens under Shared Memory (1 minute read)

This paper argues that honeytokens cannot stay invisible to trusted AI agents while remaining undetectable to an attacker who shares their information, because any trusted rule that avoids decoys can be copied, and shared memory lets a coalition pool weak fingerprints to drive Bayes classification error toward zero. The authors' fix is to keep token identity in a private reference monitor and route legitimate agents through a provenance-enforcing broker. Honeytokens remain useful sensors, but they need a separate security boundary.

An Empirical Study of Output-to-Input Loops for Black-Box Backdoor Detection in Fine-Tuned Open-Weight LLMs (1 minute read)

This paper introduces self-feeding, a black-box method for detecting backdoors in downloaded fine-tuned LLMs by feeding a model's own output back as its next input until the text drifts toward its fine-tuning data and trips a hidden trigger. Across six open-weight models and eleven attack categories, it flagged five at 92% pooled precision, versus one of 120 prompt-model pairs for a same-prompt baseline. Four-step chains hold 100% model-level precision while cutting queries 60%.

Backdoor Decontamination Dynamics in LLM Agents (1 minute read)

This paper studies whether "defensive poisoning" can scrub unknown backdoors from open-weight, tool-calling LLM agents: install a known trigger, then unlearn it and hope the hidden one clears as a side effect. Across 115 experiments on AgentDyn, defensive poisoning alone erased about 56% of original backdoors, and follow-up decontamination drove nearly all survivors to erasure, including 87% of co-resident backdoors. J-lens probing showed benign outputs restored but traces of the original trigger awareness persisting in intermediate layers.

The Next Challenge for Agentic Cybersecurity: A Realistic, Contamination-Free Reverse Engineering Benchmark (1 minute read)

SRE-Bench is the first contamination-free reverse-engineering benchmark for AI agents, built from scratch by RE experts over 5,000 hours across 19 private real-world-scale programs, 262 binary instances, and 1,572 deterministically graded tasks. Across five frontier models, RE remains largely unsolved: the strongest, GPT-5.6-sol, scores 61.4% per instance and fully solves only 31.5%. AI Guardrail Survival under Single-Cycle Agentic Self-Summarization (1 minute read)

This paper shows that when long-running agents compact their context via self-summarization, safety rules can survive as text but stop functioning, so auditing for a rule's presence is not the same as verifying it still fires. Behavioral replay found degraded rule residues drove prohibited actions 34 to 57 points more often than intact rules, and the failure is silent at runtime. Defenders should validate constraints against an external registry and test enforcement behaviorally rather than trusting LLM-judge or presence-based checks.

Slips: Behavioral Evidence Aggregation for Network Security (1 minute read)

This paper introduces Slips, a network IDS that builds host-centered behavioral profiles across time windows and aggregates evidence from independent modules into host-level decisions rather than firing per-packet alerts. Against Suricata on an expert-labeled PCAP dataset, Slips achieved 83% higher recall and a 70% higher F1 score at the profile-time-window level, with neither system producing false positives. The takeaway for defenders is that time-window evidence accumulation catches multi-connection behavior that flow-level detection misses.

On the Sensitivity to Errors in Homomorphic Computing: Single Transient Bit-flip Client-side Error Characterization (1 minute read)

This paper analyzes how single-bit faults propagate through Homomorphic Encryption, finding that CKKS-scheme homomorphic multiplication is the most error-sensitive operation and can silently amplify a single transient bit-flip into corrupted output. Because HE relies on noise injection for security, hardware- or software-induced faults evade traditional detection and produce silent data corruption, so teams deploying CKKS for privacy-preserving AI and ML workloads should add fault-tolerance checks around multiplication rather than trusting the pipeline to fail loudly.

A Study of Kernel Telemetry Options for Security-Oriented Provenance (1 minute read)

This paper surveys kernel telemetry approaches for security provenance and finds eBPF the most viable capture mechanism, backing the assessment with micro benchmarks on its overhead and container-level filtering. Classifying eight provenance systems and five capture agents, the authors find most rely on heterogeneous capture layers that cannot guarantee event integrity or availability, leaving them unfit for security use cases where tampered or dropped telemetry breaks forensic analysis.

A Runtime Decentralized Attestation and Coordinated Repair Framework for Securing Automotive ECUs (1 minute read)

This paper introduces DACER, the first automotive-security framework to co-design ECU attestation with coordinated runtime repair, unifying local firmware rollback with globally-timed reboots so a compromised ECU can be restored without triggering unsafe vehicle behavior. Built on ARM TrustZone and secure flash controllers, each ECU self-attests and self-repairs while a hierarchical architecture avoids single points of failure and holds to real-time constraints. The authors implemented it on real hardware and measured low overhead.
