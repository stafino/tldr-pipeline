The Agent Access Model (1 minute read)

Cloudflare proposed the Agent Access Model (AAM), an access-control framework for AI agents that argues human-shaped controls like SSO, device posture, and conditional access fail silently against software principals by granting too much, seeing too little, and trusting too long. Rather than making each access decision smarter, AAM shrinks the agent's capability ceiling per task-scoped run so there is less to authorize in the first place, and it separates single-principal controls available today from the unsolved problem of multiplayer access control.
