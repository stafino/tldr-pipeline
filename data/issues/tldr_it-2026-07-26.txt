GitHub, PyPI add time-absed defenses against supply chain attacks (1 minute read)

GitHub and PyPI added time-based defenses to blunt supply-chain attacks, with Dependabot now enforcing a default three-day cooldown before adopting new package versions and PyPI blocking file uploads to releases older than 14 days. The measures follow a year of high-profile npm and Python compromises, including the Shai-Hulud and GhostAction campaigns, and give IT teams a built-in window to catch malicious packages before automated updates pull them in.
