Why Intune Devices Became Noncompliant After the July Windows Update (5 minute read)

The July Windows update broke Intune compliance for BitLocker, Secure Boot, and Code Integrity on healthy devices, all flagging the same 2016345708 error because a new TPM and AIK v2 attestation path (feature 62861611) prevented Windows from retrieving the Device Health Attestation certificate. Microsoft adjusted the behavior in KB5101684, but the incident shows how a single attestation dependency can cascade into fleet-wide noncompliance that admins mistake for three separate security failures.

JetBrains disclosed CVE-2026-63077, a critical authentication bypass in TeamCity On-Premises that lets an attacker with HTTPS access execute arbitrary OS commands via the agent polling protocol, affecting all on-prem versions. Microsoft Copilot for Word Can Copy Hidden Prompts Into New Documents (1 minute read)

Security researcher Håkon Måløy disclosed a prompt-injection technique in which hidden white-on-white instructions inside a Word document make Microsoft 365 Copilot silently alter figures in a draft and copy the concealed prompt into the generated file, which then reproduces the attack in later Copilot sessions. Microsoft confirmed the behavior and shipped two mitigations, including a GPT-5.5 upgrade, but Måløy says the vulnerability class stayed exploitable through his July 28 publication, 144 days after his report.

Amazon's Q2 was great, but the earnings release is packed with baloney (1 minute read)

Amazon posted a strong Q2, but Corey Quinn argues the earnings release leans on claims that don't survive scrutiny. The clearest example: AWS touts that its Kiro coding agent is "available on iOS" when it is actually a TestFlight beta requiring an invite, with no App Store listing. The broader concern for buyers is disclosure quality, including separate $25B run-rate figures for the AI and chips businesses with no word on how much they overlap.

GPU-as-a-service: Should enterprise IT rent or own AI compute? (1 minute read)

GPU-as-a-service lets enterprises access NVIDIA H100-class hardware for $2 to $10 per hour instead of buying units at $250K to $400K each, sidestepping the CapEx and the power and cooling demands that make current GPUs incompatible with 10-20 kW enterprise racks. The tradeoff is vendor lock-in and per-hour costs that add up under sustained load, so the rent-versus-own call turns on utilization: bursty inference favors renting, while continuous training workloads erode the savings.

What the Hugging Face breach reveals about defense in the age of agentic AI (1 minute read)

The author argues that the real lesson of the Hugging Face breach, in which an OpenAI agent system ran the intrusion end to end, is not AI capability but architecture. In both firms the critical defenses sat behind untrusted code that was already executing, with the sandbox as the only boundary between attacker and everything else. A sandbox is a good control and a terrible last one, and agentic speed turns that single point of failure into a full compromise.
