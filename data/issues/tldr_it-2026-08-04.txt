Google Password Manager Attacks Could Let Malware Hijack Passkey-Protected Accounts (1 minute read)

Palo Alto Networks' Unit 42 detailed three post-compromise techniques, dubbed Pass-ta-key, against Chrome's Google Password Manager on Windows, letting malware already on a device silently obtain valid authentication assertions or extract the Security Domain Secret that decrypts a victim's synced passkeys. None of the paths break the underlying cryptography or carry a CVE, but the strongest give attackers reusable access to passkey-protected accounts from their own environment after the initial endpoint compromise.

Massive ChainDrop npm supply-chain attack infects hundreds of packages (1 minute read)

A self-propagating worm named ChainDrop compromised at least 868 npm packages across 1,381 versions, including widely used caching utilities like Keyv and Cacheable that total roughly 2 billion monthly downloads. Because the malicious releases were built through legitimate GitHub Actions workflows, they carried valid provenance, letting the infostealer harvest developer and cloud credentials from any environment that ran npm install against an affected version.

New Pass-ta-key attacks let malware hijack Google-synced passkeys (1 minute read)

Palo Alto Networks' Unit 42 disclosed "Pass-ta-key," three attacks that let malware already running on a compromised Windows device abuse Google Password Manager's synced passkeys to hijack accounts, bypass user verification, and extract private keys without admin rights or biometrics. The attacks don't break passkey cryptography but exploit how Chrome and Google's cloud authenticator handle device trust, and they succeed against services like eBay that fail to validate the User Verified flag.

Lost in Permissions: Exploring the Microsoft 365 App Ecosystem (1 minute read)

A new academic paper presents the first systematic security measurement of the Microsoft 365 third-party app ecosystem, crawling over 8,000 marketplace applications. The authors find that only 1,069 disclose both descriptions and permission sets, and that many request overly broad tenant-wide scopes like directory-wide read/write access in violation of least-privilege principles. For IT admins, the takeaway is that OAuth grants in the M365 marketplace are inconsistently disclosed and frequently over-privileged, expanding the tenant attack surface.

Real-world mainframe modernization with AI: A safe, scalable path from mainframe to cloud (2 minute read)

Google Cloud argues that enterprise mainframe modernization is not a COBOL-to-Java code conversion problem but a data and dependency problem, spanning non-relational formats like VSAM and IMS, CICS transaction monitors, and proprietary protocols that AI agents can't natively read. Its pitch pairs Gemini for code understanding with mainframe-specific tooling across four pillars, emphasizing iterative migration validated against production traffic over a high-risk "big bang" cutover.
