Ruby on Rails critical bug puts every image upload under scrutiny (2 minute read)

A critical Ruby on Rails vulnerability, CVE-2026-66066 (CVSS 9.5), lets unauthenticated attackers upload a malicious image that Active Storage passes to unhardened libvips operations, exposing sensitive files and enabling remote code execution. Enterprises running Rails apps that accept user image uploads should patch to Active Storage 7.2.3.2, 8.0.5.1, or 8.1.3.1 immediately, as the flaw requires no account or privileged access to exploit.

Nvidia is open-sourcing its cuFile APIs and the GPUDirect Storage software stack under the xio-sig consortium, letting GPUs read and write storage directly rather than routing through CPUs. IP and DNS Leaks in WebKit Affecting Proxy Browsers and iCloud Private Relay (1 minute read)

Researchers at Mysk found three WebKit features on iOS and macOS that bypass application-level proxy configuration, leaking users' real IP addresses and DNS servers from Tor browsers, other proxy browsers, and Apple's iCloud Private Relay. DNS prefetching, WebAuthn Related Origin Requests, and WebTransport each route traffic directly from the device rather than through the configured proxy, though system-level VPNs are unaffected.
