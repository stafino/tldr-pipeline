New TONTOU CPU attack bypasses Spectre v2 fixes, leaks Linux password hashes (1 minute read)

MIT CSAIL researchers disclosed TONTOU, a speculative-execution attack that defeats the neutralization-based Spectre v2 mitigations (Intel's eIBRS and AMD's Safe RET) by re-poisoning the branch predictor in the gap between when it is sanitized and when the victim uses it. Using an interrupt-injection primitive, an unprivileged local user can read arbitrary kernel memory including hashed passwords, forcing enterprises to weigh new microcode and kernel patches against the performance cost on already-mitigated Intel and AMD fleets.

Five ways to evaluate AI agent orchestration platforms (2 minute read)

The author argues that AI agent orchestration platforms have become the enterprise control plane for coordinating agents, tools, and people, and identifies more than 60 commercial and open source options built on MCP and A2A. For IT leaders, the practical evaluation criteria are governance depth, human-in-the-loop controls, observability, and clear accountability when autonomous decisions go wrong. The author expects enterprises to run multiple orchestration platforms rather than standardize on one, so procurement should weigh interoperability alongside per-platform capabilities.

Prompt injection isn't the bug, AI agent frameworks are (1 minute read)

The author argues that prompt injection is an unsolvable symptom of how AI agent frameworks are built, not a patchable defect, since agents mix untrusted input and privileged actions in the same context by design. For enterprise buyers, the implication is that no vendor patch or guardrail add-on fully closes the hole, and agent deployments should be scoped with least-privilege access and human approval on consequential actions rather than trusted to sanitize inputs.

Adding an API to networking hardware doesn’t solve management challenges (1 minute read)

The author argues that bolting an API onto traditional networking gear doesn't fix management, because the underlying problem is feature inconsistency across devices, even within a single vendor's own operating systems. He points to NAPALM supporting five vendor OSes, three of them Cisco variants, as evidence. Cloud-inspired networks win because virtual switches are uniform, so automation targets one consistent behavior rather than a patchwork of hardware quirks.
