Scriptc by Vercel: TypeScript-to-Native compiler, no JavaScript engine in binary (1 minute read)

scriptc, from Vercel Labs, compiles ordinary TypeScript into small, self-contained native binaries with no Node, V8, or JavaScript engine in the output, type-checked by the real TypeScript compiler and behaving byte-for-byte like Node. It classifies each construct as statically compiled, run dynamically through an embedded quickjs-ng engine, or rejected with a specific error code, and a `scriptc coverage` command reports what share of a program can compile to native code.
