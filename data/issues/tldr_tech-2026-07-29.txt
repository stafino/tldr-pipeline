Memory-level parallelism: AMD is the king (5 minute read)

Daniel Lemire benchmarks memory-level parallelism, the number of independent memory requests a CPU can keep in flight during cache misses, and finds AMD's recent cores lead Intel and Apple by a wide margin. His tests show top AMD chips sustaining dozens of concurrent outstanding loads, which directly speeds up pointer-chasing workloads like hash tables, graph traversal, and database indexes that bottleneck on memory latency rather than bandwidth.

Postgres LISTEN/NOTIFY Actually Scales (5 minute read)

DBOS optimized Postgres LISTEN/NOTIFY-backed streams to sustain 60K writes per second on a single server with millisecond-scale latency, rebutting the widely cited claim that the feature does not scale. A simple clustering algorithm for lists (5 minute read)

Cassidy Williams describes a greedy clustering heuristic that groups list values by repeatedly finding the nearest match to the end element and reversing the sub-list between them. Inspired by sorting Magna-Tiles, the O(n²) approach resembles pancake sort but targets grouping rather than ordering, and she walks through both the step-by-step reversals and a hand-written implementation.

Optimizing for Almost Sorted Data: Sort Pushdown in Apache DataFusion (5 minute read)

Apache DataFusion now exploits partial or undeclared sortedness in real datasets, skipping redundant sorts and pruning ORDER BY ... LIMIT queries without requiring data to be fully sorted. The engine combines plan-time sort pushdown, runtime scan reordering, and row-group pruning driven by dynamic filters, using per-file min/max statistics to discover a global sort order and bias scans toward the most-promising data.

Characterizing Metastable Faults and Failures (5 minute read)

This paper offers the first analytical causal account of metastable failures, the self-sustaining goodput collapses that persist through internal feedback loops like retries and queues long after the original trigger is gone. It reframes a metastable fault as a "sin of composition" between individually stable components, motivated by data showing four of AWS's 15 major outages over a decade were metastable, lasting 1.5 to 73 hours.
