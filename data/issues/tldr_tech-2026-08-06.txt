Don't stop early: Case-folding source code at memory speed (1 minute read)

GitHub open-sourced casefold, a Rust crate that case-folds source code at over 45 GiB/s on a single core to power case-insensitive queries across Blackbird's 480TB code-search index. The biggest ASCII speedup came from removing an optimization: sweeping the whole buffer branch-free beats stopping early at the first non-ASCII byte, and the crate folds for comparison rather than lowercasing to avoid silently wrong matches on characters like ß and İ.
